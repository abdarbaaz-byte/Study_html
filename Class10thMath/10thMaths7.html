प्रश्न 1: बिंदुओं के निम्नलिखित युग्मों के बीच की दूरियाँ ज्ञात कीजिए:

(i) (2, 3), (4, 1)

मान लीजिए A(2, 3) और B(4, 1) हैं।

दूरी सूत्र: AB = √[(x₂ − x₁)² + (y₂ − y₁)²]

AB = √[(4 − 2)² + (1 − 3)²]

= √[(2)² + (−2)²]

= √(4 + 4) = √8 = 2√2 मात्रक

उत्तर: 2√2 मात्रक

(ii) (−5, 7), (−1, 3)

मान लीजिए A(−5, 7) और B(−1, 3) हैं।

AB = √[(−1 − (−5))² + (3 − 7)²]

= √[(−1 + 5)² + (−4)²]

= √[(4)² + (−4)²]

= √(16 + 16) = √32 = 4√2 मात्रक

उत्तर: 4√2 मात्रक

(iii) (a, b), (−a, −b)

मान लीजिए A(a, b) और B(−a, −b) हैं।

AB = √[(−a − a)² + (−b − b)²]

= √[(−2a)² + (−2b)²]

= √[4a² + 4b²]

= 2√(a² + b²) मात्रक

उत्तर: 2√(a² + b²) मात्रक

प्रश्न 2: बिंदुओं (0, 0) और (36, 15) के बीच की दूरी ज्ञात कीजिए। क्या अब आप अनुच्छेद 7.2 में दिए दोनों शहरों A और B के बीच की दूरी ज्ञात कर सकते हैं?

मान लीजिए A(0, 0) और B(36, 15) हैं।

AB = √[(36 − 0)² + (15 − 0)²]

= √[(36)² + (15)²]

= √(1296 + 225)

= √1521 = 39 मात्रक

उत्तर: 39 मात्रक। हाँ, शहर A और B के बीच की दूरी 39 km है।

हिंदी स्पष्टीकरण: दूरी सूत्र का उपयोग करके 39 मात्रक प्राप्त होता है, जो वास्तविक जीवन में 39 km है।

प्रश्न 3: निर्धारित कीजिए कि क्या बिंदु (1, 5), (2, 3) और (−2, −11) संरेखी हैं।

मान लीजिए A(1, 5), B(2, 3) और C(−2, −11) हैं।

AB = √[(2 − 1)² + (3 − 5)²] = √[(1)² + (−2)²] = √(1 + 4) = √5

BC = √[(−2 − 2)² + (−11 − 3)²] = √[(−4)² + (−14)²] = √(16 + 196) = √212 = 2√53

AC = √[(−2 − 1)² + (−11 − 5)²] = √[(−3)² + (−16)²] = √(9 + 256) = √265

AB + BC = √5 + 2√53 ≈ 2.24 + 14.56 = 16.80

AC = √265 ≈ 16.28

चूँकि AB + BC ≠ AC, अतः बिंदु संरेखी नहीं हैं।

उत्तर: नहीं, ये बिंदु संरेखी नहीं हैं।

प्रश्न 4: जाँच कीजिए कि क्या बिंदु (5, −2), (6, 4) और (7, −2) एक समद्विबाहु त्रिभुज के शीर्ष हैं।

मान लीजिए A(5, −2), B(6, 4) और C(7, −2) हैं।

AB = √[(6 − 5)² + (4 + 2)²] = √[(1)² + (6)²] = √(1 + 36) = √37

BC = √[(7 − 6)² + (−2 − 4)²] = √[(1)² + (−6)²] = √(1 + 36) = √37

AC = √[(7 − 5)² + (−2 + 2)²] = √[(2)² + (0)²] = √4 = 2

यहाँ AB = BC = √37 है।

उत्तर: हाँ, चूँकि AB = BC है, अतः ये बिंदु एक समद्विबाहु त्रिभुज के शीर्ष हैं।

प्रश्न 5: किसी कक्षा में, चार मित्र बिंदुओं A, B, C और D पर बैठे हुए हैं, जैसा कि आकृति 7.8 में दर्शाया गया है। चंपा और चमेली कक्षा के अंदर आती हैं और कुछ मिनट तक देखने के बाद, चंपा चमेली से पूछती है, 'क्या तुम नहीं सोचती हो कि ABCD एक वर्ग है?' चमेली इससे सहमत नहीं है। दूरी सूत्र का प्रयोग करके, बताइए कि इनमें कौन सही है।

आकृति से निर्देशांक: A(3, 4), B(6, 7), C(9, 4), D(6, 1)

AB = √[(6 − 3)² + (7 − 4)²] = √[(3)² + (3)²] = √(9 + 9) = √18

BC = √[(9 − 6)² + (4 − 7)²] = √[(3)² + (−3)²] = √(9 + 9) = √18

CD = √[(6 − 9)² + (1 − 4)²] = √[(−3)² + (−3)²] = √(9 + 9) = √18

DA = √[(3 − 6)² + (4 − 1)²] = √[(−3)² + (3)²] = √(9 + 9) = √18

AC = √[(9 − 3)² + (4 − 4)²] = √[(6)² + (0)²] = √36 = 6

BD = √[(6 − 6)² + (1 − 7)²] = √[(0)² + (−6)²] = √36 = 6

यहाँ AB = BC = CD = DA = √18 और AC = BD = 6

उत्तर: चूँकि चारों भुजाएँ बराबर हैं और दोनों विकर्ण भी बराबर हैं, अतः ABCD एक वर्ग है। चंपा सही है।

प्रश्न 6: निम्नलिखित बिंदुओं द्वारा बनने वाले चतुर्भुज का प्रकार (यदि कोई है तो) बताइए तथा अपने उत्तर के लिए कारण भी दीजिए: (−1, −2), (1, 0), (−1, 2), (−3, 0)

मान लीजिए A(−1, −2), B(1, 0), C(−1, 2) और D(−3, 0) हैं।

AB = √[(1 + 1)² + (0 + 2)²] = √[(2)² + (2)²] = √(4 + 4) = √8 = 2√2

BC = √[(−1 − 1)² + (2 − 0)²] = √[(−2)² + (2)²] = √8 = 2√2

CD = √[(−3 + 1)² + (0 − 2)²] = √[(−2)² + (−2)²] = √8 = 2√2

DA = √[(−1 + 3)² + (−2 − 0)²] = √[(2)² + (−2)²] = √8 = 2√2

AC = √[(−1 + 1)² + (2 + 2)²] = √[(0)² + (4)²] = 4

BD = √[(−3 − 1)² + (0 − 0)²] = √[(−4)² + (0)²] = 4

यहाँ AB = BC = CD = DA = 2√2 और AC = BD = 4

उत्तर: चूँकि चारों भुजाएँ बराबर हैं और दोनों विकर्ण भी बराबर हैं, अतः यह एक वर्ग है।

प्रश्न 7: x-अक्ष पर वह बिंदु ज्ञात कीजिए जो (2, −5) और (−2, 9) से समदूरस्थ हैं।

x² − 4x + 4 + 25 = x² + 4x + 4 + 81

−4x + 29 = 4x + 85

−8x = 56

x = −7

उत्तर: अभीष्ट बिंदु (−7, 0) है।

प्रश्न 8: y का वह मान ज्ञात कीजिए, जिसके लिए बिंदु P(2, −3) और Q(10, y) के बीच की दूरी 10 मात्रक है।

प्रश्न 9: यदि Q(0, 1) बिंदुओं P(5, −3) और R(x, 6) से समदूरस्थ है, तो x के मान ज्ञात कीजिए। दूरियाँ QR और PR भी ज्ञात कीजिए।

QP = QR ⇒ QP² = QR²

(5 − 0)² + (−3 − 1)² = (x − 0)² + (6 − 1)²

25 + 16 = x² + 25

41 = x² + 25

x² = 16 ⇒ x = ±4

x = 4 या x = −4

जब x = 4, QR = √[(4 − 0)² + (6 − 1)²] = √(16 + 25) = √41

जब x = −4, QR = √[(−4 − 0)² + (6 − 1)²] = √(16 + 25) = √41

PR = √[(x − 5)² + (6 + 3)²] = √[(x − 5)² + 81]

जब x = 4, PR = √[(−1)² + 81] = √82

जब x = −4, PR = √[(−9)² + 81] = √(81 + 81) = √162 = 9√2

उत्तर: x = 4 या x = −4; QR = √41; PR = √82 (जब x = 4) या 9√2 (जब x = −4)
