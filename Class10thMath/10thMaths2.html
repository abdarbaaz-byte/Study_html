किसी बहुपद के शून्यक उन बिंदुओं के x-निर्देशांक होते हैं जहाँ उसका ग्राफ x-अक्ष को प्रतिच्छेद करता है।

कारण: ग्राफ x-अक्ष को केवल एक बिंदु पर प्रतिच्छेद करता है।

कारण: ग्राफ x-अक्ष को दो बिंदुओं पर प्रतिच्छेद करता है।

(iii) शून्यकों की संख्या: 3

कारण: ग्राफ x-अक्ष को तीन बिंदुओं पर प्रतिच्छेद करता है।

(iv) शून्यकों की संख्या: 1

कारण: ग्राफ x-अक्ष को केवल एक बिंदु पर प्रतिच्छेद करता है।

कारण: ग्राफ x-अक्ष को केवल एक बिंदु पर प्रतिच्छेद करता है।

प्रश्नावली 2.2

प्रश्न 1: निम्न द्विघात बहुपदों के शून्यक ज्ञात कीजिए और शून्यकों तथा गुणांकों के बीच के संबंध की सत्यता की जाँच कीजिए:

हल:

(i) x² – 2x – 8

बहुपद: x² – 2x – 8

गुणनखंड करने पर:

x² – 2x – 8 = x² – 4x + 2x – 8

= x(x – 4) + 2(x – 4) = (x + 2)(x – 4)

शून्यक: x + 2 = 0 या x – 4 = 0

अतः शून्यक हैं: x = –2 और x = 4

शून्यकों और गुणांकों के बीच संबंध की जाँच:

द्विघात बहुपद ax² + bx + c के लिए:

शून्यकों का योग = –b/a

शून्यकों का गुणनफल = c/a

यहाँ a = 1, b = –2, c = –8

शून्यकों का योग = (–2) + 4 = 2 = –(–2)/1 = –b/a

शून्यकों का गुणनफल = (–2) × 4 = –8 = (–8)/1 = c/a

संबंध सत्यापित हो गया।

(ii) 4s² – 4s + 1

बहुपद: 4s² – 4s + 1

गुणनखंड करने पर:

4s² – 4s + 1 = (2s – 1)²

शून्यक: 2s – 1 = 0

अतः शून्यक है: s = 1/2 (दो बार)

शून्यकों और गुणांकों के बीच संबंध की जाँच:

यहाँ a = 4, b = –4, c = 1

शून्यकों का योग = 1/2 + 1/2 = 1 = –(–4)/4 = –b/a

शून्यकों का गुणनफल = (1/2) × (1/2) = 1/4 = 1/4 = c/a

संबंध सत्यापित हो गया।

(iii) 6x² – 3 – 7x

बहुपद: 6x² – 7x – 3

गुणनखंड करने पर:

6x² – 7x – 3 = 6x² – 9x + 2x – 3

= 3x(2x – 3) + 1(2x – 3) = (3x + 1)(2x – 3)

शून्यक: 3x + 1 = 0 या 2x – 3 = 0

अतः शून्यक हैं: x = –1/3 और x = 3/2

शून्यकों और गुणांकों के बीच संबंध की जाँच:

यहाँ a = 6, b = –7, c = –3

शून्यकों का योग = (–1/3) + (3/2) = 7/6 = –(–7)/6 = –b/a

शून्यकों का गुणनफल = (–1/3) × (3/2) = –1/2 = (–3)/6 = c/a

संबंध सत्यापित हो गया।

(iv) 4u² + 8u

बहुपद: 4u² + 8u

गुणनखंड करने पर:

4u² + 8u = 4u(u + 2)

शून्यक: 4u = 0 या u + 2 = 0

अतः शून्यक हैं: u = 0 और u = –2

शून्यकों और गुणांकों के बीच संबंध की जाँच:

यहाँ a = 4, b = 8, c = 0

शून्यकों का योग = 0 + (–2) = –2 = –8/4 = –b/a

शून्यकों का गुणनफल = 0 × (–2) = 0 = 0/4 = c/a

संबंध सत्यापित हो गया।

(v) t² – 15

बहुपद: t² – 15

गुणनखंड करने पर:

t² – 15 = (t – √15)(t + √15)

शून्यक: t – √15 = 0 या t + √15 = 0

अतः शून्यक हैं: t = √15 और t = –√15

शून्यकों और गुणांकों के बीच संबंध की जाँच:

यहाँ a = 1, b = 0, c = –15

शून्यकों का योग = √15 + (–√15) = 0 = –0/1 = –b/a

शून्यकों का गुणनफल = √15 × (–√15) = –15 = (–15)/1 = c/a

संबंध सत्यापित हो गया।

(vi) 3x² – x – 4

बहुपद: 3x² – x – 4

गुणनखंड करने पर:

3x² – x – 4 = 3x² – 4x + 3x – 4

= x(3x – 4) + 1(3x – 4) = (x + 1)(3x – 4)

शून्यक: x + 1 = 0 या 3x – 4 = 0

अतः शून्यक हैं: x = –1 और x = 4/3

शून्यकों और गुणांकों के बीच संबंध की जाँच:

यहाँ a = 3, b = –1, c = –4

शून्यकों का योग = (–1) + (4/3) = 1/3 = –(–1)/3 = –b/a

शून्यकों का गुणनफल = (–1) × (4/3) = –4/3 = (–4)/3 = c/a

संबंध सत्यापित हो गया।

प्रश्न 2: एक द्विघात बहुपद ज्ञात कीजिए, जिसके शून्यकों का योग तथा गुणनफल क्रमशः दी गई संख्याएँ हैं:

हल:

यदि किसी द्विघात बहुपद के शून्यक α और β हों, तो वह बहुपद निम्न प्रकार लिखा जा सकता है:

x² – (α + β)x + αβ

(i) 1 4 , –1

शून्यकों का योग = 1/4

शून्यकों का गुणनफल = –1

अभीष्ट बहुपद:

x² – (1/4)x + (–1)

x² – (1/4)x – 1

हरों को हटाने के लिए 4 से गुणा करने पर:

4x² – x – 4

उत्तर: 4x² – x – 4

(ii) √2, 1 3

शून्यकों का योग = √2

शून्यकों का गुणनफल = 1/3

अभीष्ट बहुपद:

x² – (√2)x + (1/3)

हरों को हटाने के लिए 3 से गुणा करने पर:

3x² – 3√2x + 1

उत्तर: 3x² – 3√2x + 1

(iii) 0, √5

शून्यकों का योग = 0

शून्यकों का गुणनफल = √5

अभीष्ट बहुपद:

x² – (0)x + (√5)

x² + √5

उत्तर: x² + √5

(iv) 1, 1

शून्यकों का योग = 1

शून्यकों का गुणनफल = 1

अभीष्ट बहुपद:

x² – (1)x + (1)

x² – x + 1

उत्तर: x² – x + 1

(v) – 1 4 , 1 4

शून्यकों का योग = –1/4 + 1/4 = 0

शून्यकों का गुणनफल = (–1/4) × (1/4) = –1/16

अभीष्ट बहुपद:

x² – (0)x + (–1/16)

x² – 1/16

हरों को हटाने के लिए 16 से गुणा करने पर:

16x² – 1

उत्तर: 16x² – 1

(vi) 4, 1

शून्यकों का योग = 4

शून्यकों का गुणनफल = 1

अभीष्ट बहुपद:

x² – (4)x + (1)

x² – 4x + 1

उत्तर: x² – 4x + 1
