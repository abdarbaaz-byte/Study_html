प्रश्नावली 9.2 (हल का सत्यापन)

प्रश्न 1: y = ex + 1 : y'' - y' = 0

हल: y = ex + 1

y' = ex, y'' = ex

y'' - y' = ex - ex = 0 = दायाँ पक्ष

अतः सत्यापित हुआ।

प्रश्न 2: y = x2 + 2x + C : y' - 2x - 2 = 0

हल: y = x2 + 2x + C

y' = 2x + 2

y' - 2x - 2 = (2x + 2) - 2x - 2 = 0

अतः सत्यापित हुआ।

प्रश्न 3: y = cos x + C : y' + sin x = 0

हल: y = cos x + C

y' = -sin x

y' + sin x = -sin x + sin x = 0

अतः सत्यापित हुआ।

प्रश्न 4: y = √(1 + x2) : y' = xy1 + x2

हल: y = (1 + x2)1/2

y' = 12(1 + x2)-1/2 · 2x = x√(1 + x2)

y' = xy1 + x2 (क्योंकि y = √(1 + x2))

अतः सत्यापित हुआ।

प्रश्न 5: y = Ax : xy' = y

हल: y = Ax

y' = A

xy' = x(A) = Ax = y

अतः सत्यापित हुआ।

प्रश्न 6: y = x sin x : xy' = y + x√(x2 - y2)

हल: y = x sin x

y' = sin x + x cos x

xy' = x sin x + x2 cos x = y + x2 cos x

अब √(x2 - y2) = √(x2 - x2 sin2x) = √(x2 cos2x) = x cos x

y + x√(x2 - y2) = y + x(x cos x) = y + x2 cos x

अतः सत्यापित हुआ।

प्रश्न 7: xy = log y + C : y' = y21 - xy

हल: xy = log y + C

अवकलन करने पर: y + x y' = 1y y'

y = y'(1y - x) = y'(1 - xyy)

y' = y21 - xy

अतः सत्यापित हुआ।

प्रश्न 8: y - cos y = x : (y sin y + cos y + x)y' = y

हल: y - cos y = x

अवकलन करने पर: y' + sin y y' = 1 ⇒ y'(1 + sin y) = 1

अब LHS: (y sin y + cos y + x)y'

= (y sin y + cos y + y - cos y) y' (क्योंकि x = y - cos y)

= (y sin y + y)y' = y(1 + sin y)y' = y(1) = y

अतः सत्यापित हुआ।

प्रश्न 9: x + y = tan-1y : y2y' + y2 + 1 = 0

हल: x + y = tan-1y

अवकलन करने पर: 1 + y' = 11 + y2 y'

1 = y'(11 + y2 - 1) = y'(-y21 + y2)

y' = -1 + y2y2

y2y' + y2 + 1 = y2(-1 + y2y2) + y2 + 1 = -(1 + y2) + y2 + 1 = 0

अतः सत्यापित हुआ।

प्रश्न 10: y = √(a2 - x2), x ∈ (-a, a) : x + ydydx = 0

हल: y = √(a2 - x2) ⇒ y2 = a2 - x2

अवकलन करने पर: 2y y' = -2x ⇒ x + y y' = 0

अतः सत्यापित हुआ।
