प्रश्न 1: sin-1(-12) का मुख्य मान ज्ञात कीजिए।

मान लीजिए sin-1(-12) = y, तो sin y = -12 होगा।

हमें ज्ञात है कि sin-1 का मुख्य शाखा परिसर [-π2, π2] होता है।

चूँकि sin(-π6) = -12 है,

उत्तर: अतः sin-1(-12) का मुख्य मान -π6 है।

हिंदी स्पष्टीकरण: मुख्य शाखा के परिसर (Principal Range) का ध्यान रखना आवश्यक है, जो कि [-π2, π2] है।

प्रश्नावली 2.2

प्रश्न 1: सिद्ध कीजिए कि 3sin-1 x = sin-1(3x - 4x3), x ∈ [-12, 12]

हल: मान लीजिए x = sin θ, तो θ = sin-1 x होगा।

अब दाएँ पक्ष (RHS) में x का मान रखने पर:

3x - 4x3 = 3sin θ - 4sin3 θ

हम जानते हैं कि sin 3θ = 3sin θ - 4sin3 θ होता है, इसलिए:

sin-1(3x - 4x3) = sin-1(sin 3θ) = 3θ

चूँकि x ∈ [-12, 12], तो θ ∈ [-π6, π6] और 3θ ∈ [-π2, π2] (मुख्य शाखा में) होगा।

इसलिए, sin-1(sin 3θ) = 3θ = 3sin-1 x

अतः सिद्ध हुआ।

प्रश्न 2: सिद्ध कीजिए कि 3cos-1 x = cos-1(4x3 - 3x), x ∈ [12, 1]

हल: मान लीजिए x = cos θ, तो θ = cos-1 x होगा।

दाएँ पक्ष में मान रखने पर:

4x3 - 3x = 4cos3 θ - 3cos θ

हम जानते हैं कि cos 3θ = 4cos3 θ - 3cos θ, इसलिए:

cos-1(4x3 - 3x) = cos-1(cos 3θ) = 3θ

चूँकि x ∈ [12, 1], तो θ ∈ [0, π3] और 3θ ∈ [0, π] (मुख्य शाखा में) होगा।

इसलिए, cos-1(cos 3θ) = 3θ = 3cos-1 x

अतः सिद्ध हुआ।

प्रश्न 3: सरलतम रूप में लिखिए: tan-1 ( √1+x2 - 1x ), x ≠ 0

हल: मान लीजिए x = tan θ, तो θ = tan-1 x होगा।

अब व्यंजक में मान रखने पर:

tan-1 ( √1+tan2θ - 1tan θ )

हम जानते हैं कि 1 + tan2θ = sec2θ, इसलिए:

tan-1 ( sec θ - 1tan θ )

इसे sine और cosine में बदलने पर:

tan-1 ( 1cos θ - 1sin θcos θ )

= tan-1 ( 1 - cos θsin θ )

अर्धकोण सूत्र से: 1 - cos θsin θ = tan(θ2)

= tan-1(tan(θ2)) = θ2 = 12 tan-1 x

उत्तर: 12 tan-1 x

प्रश्न 4: सरलतम रूप में लिखिए: tan-1 ( √(1 - cos x1 + cos x) ), 0 < x < π

हल: हम जानते हैं कि:

1 - cos x = 2sin2(x2) और 1 + cos x = 2cos2(x2)

व्यंजक में मान रखने पर:

tan-1 ( √(2sin2(x2)2cos2(x2)) )

= tan-1 ( √(tan2(x2)) )

= tan-1 ( tan(x2) )

चूँकि 0 < x < π, इसलिए 0 < x2 < π2 (मुख्य शाखा में) होगा।

अतः tan-1(tan(x2)) = x2

उत्तर: x2

प्रश्न 5: सरलतम रूप में लिखिए: tan-1 ( cos x - sin xcos x + sin x ), -π4 < x < 3π4

हल: अंश और हर दोनों में cos x से भाग देने पर:

tan-1 ( 1 - tan x1 + tan x )

हम जानते हैं कि tan(π4 - x) = 1 - tan x1 + tan x होता है।

अतः व्यंजक बनता है: tan-1(tan(π4 - x))

चूँकि -π4 < x < 3π4, तो -π4 < π4 - x < π2 (मुख्य शाखा में) होगा।

इसलिए, tan-1(tan(π4 - x)) = π4 - x

उत्तर: π4 - x

प्रश्न 6: सरलतम रूप में लिखिए: tan-1 ( x√a2 - x2 ), |x| < a

हल: मान लीजिए x = a sin θ, तो θ = sin-1(xa) होगा।

व्यंजक में मान रखने पर:

tan-1 ( a sin θ√a2 - a2sin2θ )

= tan-1 ( a sin θ√a2cos2θ )

= tan-1 ( a sin θa cos θ ) = tan-1(tan θ) = θ

इसलिए, θ = sin-1(xa)

उत्तर: sin-1(xa)

प्रश्न 7: सरलतम रूप में लिखिए: tan-1 ( 3a2x - x3a3 - 3ax2 ), a > 0; -a√3 < x < a√3

हल: मान लीजिए x = a tan θ, तो θ = tan-1(xa) होगा।

व्यंजक में मान रखने पर:

tan-1 ( 3a3tan θ - a3tan3θa3 - 3a3tan2θ )

= tan-1 ( 3tan θ - tan3θ1 - 3tan2θ )

= tan-1(tan 3θ) = 3θ

चूँकि -a√3 < x < a√3, तो θ ∈ (-π6, π6) और 3θ ∈ (-π2, π2) होगा।

इसलिए, 3θ = 3 tan-1(xa)

उत्तर: 3 tan-1(xa)

प्रश्न 9: मान ज्ञात कीजिए: tan-1 [sin-1(2x1+x2) + cos-1(1-y21+y2)], |x| < 1, y > 0 तथा xy < 1

2(tan-1x + tan-1y)

= 2 tan-1 ( x+y1-xy )

प्रश्न 10: मान ज्ञात कीजिए: sin-1(sin(2π3))

हल: हमें ज्ञात है कि sin-1(sin x) = x केवल तभी होता है जब x ∈ [-π2, π2] हो।

यहाँ x = 2π3 है, जो कि मुख्य शाखा में नहीं है।

लेकिन sin(2π3) = sin(π - 2π3) = sin(π3)

और π3 ∈ [-π2, π2]

इसलिए, sin-1(sin(2π3)) = sin-1(sin(π3)) = π3

उत्तर: π3

प्रश्न 11: मान ज्ञात कीजिए: tan-1(tan(3π4))

यहाँ 3π4 मुख्य शाखा में नहीं है।

हम जानते हैं कि tan(3π4) = tan(3π4 - π) = tan(-π4)

इसलिए, tan-1(tan(3π4)) = tan-1(tan(-π4)) = -π4

उत्तर: -π4

प्रश्न 12: मान ज्ञात कीजिए: tan( sin-1(35) + cot-1(32) )

हल: मान लीजिए sin-1(35) = A, तो sin A = 35। पाइथागोरस प्रमेय से tan A = 34 होगा।

मान लीजिए cot-1(32) = B, तो cot B = 32 ⇒ tan B = 23।

अब हमें tan(A + B) का मान निकालना है:

tan(A + B) = tan A + tan B1 - tan A · tan B

= 34 + 231 - (34)(23)

= 17121 - 12

= 171212 = 176

उत्तर: 176

प्रश्न 14: sin( π3 - sin-1(-12) ) का मान है:
