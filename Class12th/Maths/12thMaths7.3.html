प्रश्नावली 7.5 (आंशिक भिन्नों द्वारा समाकलन)

प्रश्न 1: ∫ x(x+1)(x+2) dx

हल: आंशिक भिन्न में विभाजित करने पर:

x(x+1)(x+2) = Ax+1 + Bx+2

x = A(x+2) + B(x+1)

x = -1 रखने पर: -1 = A(1) ⇒ A = -1

x = -2 रखने पर: -2 = B(-1) ⇒ B = 2

= ∫ (-1x+1 + 2x+2) dx

उत्तर: = -log|x+1| + 2log|x+2| + C

प्रश्न 2: ∫ 1x2 - 9 dx

हल: = ∫ 1(x-3)(x+3) dx

सूत्र: ∫ dxx2 - a2 = 12a log|x-ax+a| + C

यहाँ a = 3 है।

उत्तर: = 16 log|x-3x+3| + C

प्रश्न 3: ∫ 3x-1(x-1)(x-2)(x-3) dx

हल: 3x-1(x-1)(x-2)(x-3) = Ax-1 + Bx-2 + Cx-3

3x-1 = A(x-2)(x-3) + B(x-1)(x-3) + C(x-1)(x-2)

x = 1 रखने पर: 2 = A(-1)(-2) ⇒ A = 1

x = 2 रखने पर: 5 = B(1)(-1) ⇒ B = -5

x = 3 रखने पर: 8 = C(2)(1) ⇒ C = 4

= ∫ (1x-1 - 5x-2 + 4x-3) dx

उत्तर: = log|x-1| - 5log|x-2| + 4log|x-3| + C

प्रश्न 4: ∫ x(x-1)(x-2)(x-3) dx

हल: x(x-1)(x-2)(x-3) = Ax-1 + Bx-2 + Cx-3

x = A(x-2)(x-3) + B(x-1)(x-3) + C(x-1)(x-2)

x = 1 रखने पर: 1 = A(-1)(-2) ⇒ A = 1/2

x = 2 रखने पर: 2 = B(1)(-1) ⇒ B = -2

x = 3 रखने पर: 3 = C(2)(1) ⇒ C = 3/2

= ∫ (1/2x-1 - 2x-2 + 3/2x-3) dx

उत्तर: = 12 log|x-1| - 2log|x-2| + 32 log|x-3| + C

प्रश्न 5: ∫ 2xx2+3x+2 dx

हल: x2+3x+2 = (x+1)(x+2)

2x(x+1)(x+2) = Ax+1 + Bx+2

2x = A(x+2) + B(x+1)

x = -1 रखने पर: -2 = A(1) ⇒ A = -2

x = -2 रखने पर: -4 = B(-1) ⇒ B = 4

= ∫ (-2x+1 + 4x+2) dx

उत्तर: = -2log|x+1| + 4log|x+2| + C

प्रश्न 6: ∫ 1-x2x(1-2x) dx

हल: अंश की घात हर की घात के बराबर है। विभाजन करने पर:

1-x2x(1-2x) = 12 + 2-x2x(1-2x)

2-x2x(1-2x) = Ax + B1-2x

2-x = A(1-2x) + Bx ⇒ x=0 पर A=2, x=1/2 पर B=3

= ∫ [12 + 1x + 31-2x] dx (ध्यान दें: A=2, B=3 को 2x(1-2x) के साथ समायोजित करने पर 1/x + 3/(1-2x) प्राप्त होता है)

उत्तर: = x2 + log|x| - 32 log|1-2x| + C

प्रश्न 7: ∫ x(x2+1)(x-1) dx

हल: x(x-1)(x2+1) = Ax-1 + Bx+Cx2+1

x = A(x2+1) + (Bx+C)(x-1)

x = 1 पर: 1 = 2A ⇒ A = 1/2

x = 0 पर: 0 = A - C ⇒ C = 1/2

x2 का गुणांक: 0 = A+B ⇒ B = -1/2

= ∫ [1/2x-1 + (-1/2)x + 1/2x2+1] dx

उत्तर: = 12 log|x-1| - 14 log(x2+1) + 12 tan-1x + C

प्रश्न 8: ∫ x(x-1)2(x+2) dx

हल: x(x-1)2(x+2) = Ax-1 + B(x-1)2 + Cx+2

x = A(x-1)(x+2) + B(x+2) + C(x-1)2

x = 1 पर: 1 = 3B ⇒ B = 1/3

x = -2 पर: -2 = 9C ⇒ C = -2/9

x2 का गुणांक: 0 = A+C ⇒ A = 2/9

= ∫ [2/9x-1 + 1/3(x-1)2 - 2/9x+2] dx

उत्तर: = 29 log|x-1x+2| - 13(x-1) + C

प्रश्न 9: ∫ 3x+5x3-x2-x+1 dx

हल: हर = x2(x-1) - 1(x-1) = (x-1)(x2-1) = (x-1)2(x+1)

3x+5(x-1)2(x+1) = Ax-1 + B(x-1)2 + Cx+1

3x+5 = A(x-1)(x+1) + B(x+1) + C(x-1)2

x = 1 पर: 8 = 2B ⇒ B = 4 (प्रश्न में गलती से B=2 छपा है, सही B=4 है)

x = -1 पर: 2 = 4C ⇒ C = 1/2

x2 का गुणांक: 0 = A+C ⇒ A = -1/2

उत्तर: = -12 log|x-1| - 4x-1 + 12 log|x+1| + C

प्रश्न 10: ∫ 2x-3(x2-1)(2x+3) dx

हल: = ∫ 2x-3(x-1)(x+1)(2x+3) dx

= Ax-1 + Bx+1 + C2x+3

2x-3 = A(x+1)(2x+3) + B(x-1)(2x+3) + C(x-1)(x+1)

x = 1 पर: -1 = 10A ⇒ A = -1/10

x = -1 पर: -5 = -2B ⇒ B = 5/2

x = -3/2 पर: -6 = 5/4 C ⇒ C = -24/5? (प्रश्न में कुछ भिन्न है, मानक हल: A=-1/10, B=-5/2, C=12/5)

उत्तर: = -110 log|x-1| - 52 log|x+1| + 65 log|2x+3| + C

प्रश्न 11: ∫ 5x(x+1)(x2-4) dx

हल: = ∫ 5x(x+1)(x-2)(x+2) dx

= Ax+1 + Bx-2 + Cx+2

5x = A(x-2)(x+2) + B(x+1)(x+2) + C(x+1)(x-2)

x = -1 पर: -5 = -3A ⇒ A = 5/3

x = 2 पर: 10 = 12B ⇒ B = 5/6

x = -2 पर: -10 = 4C ⇒ C = -5/2

उत्तर: = 53 log|x+1| + 56 log|x-2| - 52 log|x+2| + C

प्रश्न 12: ∫ x3+x+1x2-1 dx

हल: विभाजन करने पर: = x + 2x+1x2-1

= ∫ x dx + ∫ 2xx2-1 dx + ∫ 1x2-1 dx

उत्तर: = x22 + log|x2-1| + 12 log|x-1x+1| + C

प्रश्न 13: ∫ 2(1-x)(1+x2) dx

हल: 2(1-x)(1+x2) = A1-x + Bx+C1+x2

2 = A(1+x2) + (Bx+C)(1-x)

x = 1 पर: 2 = 2A ⇒ A = 1

x = 0 पर: 2 = A+C ⇒ C = 1

x2 का गुणांक: 0 = A-B ⇒ B = 1

= ∫ [11-x + x+11+x2] dx

उत्तर: = -log|1-x| + 12 log(1+x2) + tan-1x + C

प्रश्न 14: ∫ 3x-1(x+2)2 dx

हल: 3x-1(x+2)2 = Ax+2 + B(x+2)2

3x-1 = A(x+2) + B ⇒ x = -2 पर B = -7, A = 3

= ∫ [3x+2 - 7(x+2)2] dx

उत्तर: = 3log|x+2| + 7x+2 + C

प्रश्न 15: ∫ 1x4-1 dx

हल: = ∫ 1(x2-1)(x2+1) dx = 12 ∫ [1x2-1 - 1x2+1] dx

= 12 [12 log|x-1x+1|] - 12 tan-1x + C

उत्तर: = 14 log|x-1x+1| - 12 tan-1x + C

प्रश्न 16: ∫ 1x(xn+1) dx

हल: अंश और हर को xn-1 से गुणा करने पर:

= ∫ xn-1xn(xn+1) dx

मान लीजिए xn = t, तो nxn-1dx = dt

= 1n ∫ 1t(t+1) dt = 1n ∫ [1t - 1t+1] dt

= 1n [log|t| - log|t+1|] + C

उत्तर: = 1n log|xnxn+1| + C

प्रश्न 17: ∫ cos x(1-sin x)(2-sin x) dx

हल: मान लीजिए sin x = t, तो cos x dx = dt

= ∫ 1(1-t)(2-t) dt = ∫ [-11-t + 12-t] dt

= log|1-t| - log|2-t| + C

उत्तर: = log|1-sin x2-sin x| + C (या log|2-sin x1-sin x| + C)

प्रश्न 18: ∫ (x2+1)(x2+2)(x2+3)(x2+4) dx

हल: = ∫ x4+3x2+2x4+7x2+12 dx

विभाजन करने पर: = ∫ [1 - 4x2+10(x2+3)(x2+4)] dx

= x - ∫ [2x2+3 + 2x2+4] dx

उत्तर: = x - 2√3 tan-1(x√3) + tan-1(x2) + C

प्रश्न 19: ∫ 2x(x2+1)(x2+3) dx

हल: मान लीजिए x2 = t, तो 2x dx = dt

= ∫ 1(t+1)(t+3) dt = 12 ∫ [1t+1 - 1t+3] dt

उत्तर: = 12 log|x2+1x2+3| + C

प्रश्न 20: ∫ 1x(x4-1) dx

हल: अंश और हर को x3 से गुणा करने पर:

= ∫ x3x4(x4-1) dx

मान लीजिए x4 = t, तो 4x3dx = dt

= 14 ∫ 1t(t-1) dt = 14 ∫ [1t-1 - 1t] dt

उत्तर: = 14 log|x4-1x4| + C

प्रश्न 21: ∫ 1ex-1 dx

हल: अंश और हर को ex से भाग देने पर:

= ∫ e-x1-e-x dx

मान लीजिए 1-e-x = t, तो e-xdx = dt

= ∫ 1t dt = log|t| + C

उत्तर: = log|1-e-x| + C

प्रश्न 22: ∫ x(x-1)(x-2) dx बराबर है:

(A) log|(x-1)2x-2| + C   (B) log|(x-2)2x-1| + C   (C) log|(x-1)x-2|2 + C   (D) log|(x-1)(x-2)| + C

हल: x(x-1)(x-2) = -1x-1 + 2x-2

= -log|x-1| + 2log|x-2| + C = log|(x-2)2x-1| + C

उत्तर: विकल्प (B) सही है।

प्रश्न 23: ∫ dxx(x2+1) बराबर है:

(A) log|x| - 12log(x2+1) + C   (B) log|x| + 12log(x2+1) + C   (C) -log|x| + 12log(x2+1) + C   (D) 12log|x| + log(x2+1) + C

हल: 1x(x2+1) = 1x - xx2+1

= ∫ (1x - xx2+1) dx = log|x| - 12log(x2+1) + C

उत्तर: विकल्प (A) सही है।

प्रश्नावली 7.6 (खंडशः समाकलन)

प्रश्न 1: ∫ x sin x dx

हल: प्रथम फलन = x, द्वितीय फलन = sin x

= x∫ sin x dx - ∫ [ddx(x) ∫ sin x dx] dx

= x(-cos x) - ∫ 1 · (-cos x) dx = -x cos x + sin x + C

प्रश्न 2: ∫ x sin 3x dx

हल: प्रथम फलन = x, द्वितीय फलन = sin 3x

= x(-cos 3x3) - ∫ 1 · (-cos 3x3) dx

= -x3 cos 3x + 13 · sin 3x3 + C

उत्तर: = -x3 cos 3x + 19 sin 3x + C

प्रश्न 3: ∫ x2 ex dx

हल: खंडशः समाकलन का दो बार प्रयोग करने पर:

= x2ex - ∫ 2x ex dx = x2ex - 2[x ex - ∫ ex dx]

= x2ex - 2xex + 2ex + C

प्रश्न 4: ∫ x log x dx

हल: प्रथम फलन = log x, द्वितीय फलन = x

= (log x)x22 - ∫ 1x · x22 dx = x22 log x - 12 ∫ x dx

उत्तर: = x22 log x - x24 + C

प्रश्न 5: ∫ x log 2x dx

हल: प्रथम फलन = log 2x, द्वितीय फलन = x

= (log 2x)x22 - ∫ 12x · 2 · x22 dx = x22 log 2x - x24 + C

प्रश्न 6: ∫ x2 log x dx

हल: प्रथम फलन = log x, द्वितीय फलन = x2

= (log x)x33 - ∫ 1x · x33 dx = x33 log x - 13 ∫ x2 dx

उत्तर: = x33 log x - x39 + C

प्रश्न 7: ∫ x sin-1x dx

हल: प्रथम फलन = sin-1x, द्वितीय फलन = x

= (sin-1x)x22 - ∫ 1√(1-x2) · x22 dx

दूसरे समाकलन में x = sin θ रखने पर हल करने से प्राप्त होता है:

उत्तर: = 2x2-14 sin-1x + x4 √(1-x2) + C

प्रश्न 8: ∫ x tan-1x dx

हल: प्रथम फलन = tan-1x, द्वितीय फलन = x

= (tan-1x)x22 - 12 ∫ x21+x2 dx = x22 tan-1x - 12 ∫ (1 - 11+x2) dx

उत्तर: = x22 tan-1x - x2 + 12 tan-1x + C = (x2+1)2 tan-1x - x2 + C

प्रश्न 9: ∫ x cos-1x dx

हल: प्रथम फलन = cos-1x, द्वितीय फलन = x

= (cos-1x)x22 - ∫ -1√(1-x2) · x22 dx

उत्तर: = 2x2-14 cos-1x - x4 √(1-x2) + C

प्रश्न 10: ∫ (sin-1x)2 dx

हल: प्रथम फलन = (sin-1x)2, द्वितीय फलन = 1

= x(sin-1x)2 - 2∫ x sin-1x · 1√(1-x2) dx

दूसरे समाकलन को हल करने पर:

उत्तर: = x(sin-1x)2 + 2√(1-x2) sin-1x - 2x + C

प्रश्न 11: ∫ x cos-1x√(1-x2) dx

हल: प्रथम फलन = cos-1x, द्वितीय फलन = x√(1-x2)

= (cos-1x)(-√(1-x2)) - ∫ -1√(1-x2) · (-√(1-x2)) dx

= -√(1-x2) cos-1x - ∫ 1 dx

उत्तर: = -√(1-x2) cos-1x - x + C

प्रश्न 12: ∫ x sec2x dx

हल: प्रथम फलन = x, द्वितीय फलन = sec2x

= x tan x - ∫ 1 · tan x dx

= x tan x - log|sec x| + C

प्रश्न 13: ∫ tan-1x dx

हल: प्रथम फलन = tan-1x, द्वितीय फलन = 1

= x tan-1x - ∫ x1+x2 dx

मान लीजिए 1+x2 = t ⇒ 2x dx = dt

उत्तर: = x tan-1x - 12 log(1+x2) + C

प्रश्न 14: ∫ x (log x)2 dx

हल: प्रथम फलन = (log x)2, द्वितीय फलन = x

= (log x)2 x22 - ∫ 2 log x · 1x · x22 dx = x22(log x)2 - ∫ x log x dx

प्रश्न 4 से ∫ x log x dx = x22 log x - x24

उत्तर: = x22(log x)2 - x22 log x + x24 + C

प्रश्न 15: ∫ (x2+1) log x dx

हल: प्रथम फलन = log x, द्वितीय फलन = x2+1

= log x (x33 + x) - ∫ 1x (x33 + x) dx

= (x33 + x) log x - ∫ (x23 + 1) dx

उत्तर: = (x33 + x) log x - x39 - x + C

प्रश्न 16: ∫ ex(sin x + cos x) dx

हल: यह ∫ ex[f(x) + f'(x)] dx = exf(x) + C के रूप में है, जहाँ f(x) = sin x और f'(x) = cos x

उत्तर: = ex sin x + C

प्रश्न 17: ∫ (1x - 1x2) ex dx

हल: यहाँ f(x) = 1x, तो f'(x) = -1x2

उत्तर: = exx + C

प्रश्न 18: ∫ ex (1+sin x1+cos x) dx

हल: 1+sin x1+cos x = 1 + 2sin(x/2)cos(x/2)2cos2(x/2) = 12 sec2(x/2) + tan(x/2)

यह f(x) = tan(x/2) और f'(x) = 12 sec2(x/2) के रूप में है।

उत्तर: = ex tan(x/2) + C

प्रश्न 19: ∫ ex (1x - 1x2) dx

हल: प्रश्न 17 के समान, यहाँ f(x) = 1x और f'(x) = -1x2

उत्तर: = exx + C

प्रश्न 20: ∫ ex(1-sin x)(1-cos x) dx

हल: 1-sin x1-cos x = 1 - 2sin(x/2)cos(x/2)2sin2(x/2) = 12 cosec2(x/2) - cot(x/2)

यहाँ f(x) = -cot(x/2), f'(x) = 12 cosec2(x/2)

उत्तर: = -ex cot(x/2) + C

प्रश्न 21: ∫ e2x sin x dx

हल: खंडशः समाकलन का दो बार प्रयोग करने पर:

I = e2x(-cos x) - ∫ 2e2x(-cos x) dx = -e2x cos x + 2∫ e2x cos x dx

पुनः खंडशः करने पर: I = -e2x cos x + 2[e2x sin x - 2∫ e2x sin x dx]

I = -e2x cos x + 2e2x sin x - 4I ⇒ 5I = e2x(2sin x - cos x)

उत्तर: = e2x5 (2sin x - cos x) + C

प्रश्न 22: ∫ sin-1 (2x1+x2) dx

हल: मान लीजिए x = tan θ ⇒ dx = sec2θ dθ

= ∫ sin-1(sin 2θ) sec2θ dθ = ∫ 2θ sec2θ dθ

खंडशः समाकलन से: = 2θ tanθ - 2∫ tanθ dθ = 2θ tanθ - 2log|secθ| + C

उत्तर: = 2x tan-1x - log(1+x2) + C

प्रश्न 23: ∫ x2 ex3 dx बराबर है:

(A) 13 ex3 + C   (B) 13 ex2 + C   (C) 12 ex3 + C   (D) 13 ex2 + C

हल: मान लीजिए x3 = t ⇒ 3x2dx = dt

= 13 ∫ et dt = 13 et + C = 13 ex3 + C

उत्तर: विकल्प (A) सही है।

प्रश्न 24: ∫ ex sec x (1 + tan x) dx बराबर है:

(A) ex cos x + C   (B) ex sec x + C   (C) ex sin x + C   (D) ex tan x + C

हल: यहाँ f(x) = sec x और f'(x) = sec x tan x

= ∫ ex (sec x + sec x tan x) dx

उत्तर: = ex sec x + C। विकल्प (B) सही है।

प्रश्नावली 7.7 (विशिष्ट प्रकार के समाकलन)

प्रश्न 1: ∫ √(4 - x2) dx

हल: सूत्र ∫ √(a2 - x2) dx = x2√(a2 - x2) + a22 sin-1(xa) + C का प्रयोग करने पर (यहाँ a=2):

उत्तर: = x2√(4-x2) + 2 sin-1(x2) + C

प्रश्न 2: ∫ √(1 - 4x2) dx

हल: = ∫ √(1 - (2x)2) dx

मान लीजिए 2x = t ⇒ 2dx = dt

= 12 ∫ √(1 - t2) dt = 12 [t2√(1-t2) + 12 sin-1t] + C

उत्तर: = x2√(1-4x2) + 14 sin-1(2x) + C

प्रश्न 3: ∫ √(x2 + 4x + 6) dx

हल: x2 + 4x + 6 = (x+2)2 + 2

मान लीजिए x+2 = t ⇒ dx = dt

= ∫ √(t2 + (√2)2) dt

सूत्र: ∫ √(t2+a2) dt = t2√(t2+a2) + a22 log|t + √(t2+a2)|

उत्तर: = x+22√(x2+4x+6) + log|x+2 + √(x2+4x+6)| + C

प्रश्न 4: ∫ √(x2 + 4x + 1) dx

हल: x2 + 4x + 1 = (x+2)2 - 3

मान लीजिए x+2 = t ⇒ dx = dt

= ∫ √(t2 - (√3)2) dt

सूत्र: ∫ √(t2-a2) dt = t2√(t2-a2) - a22 log|t + √(t2-a2)|

उत्तर: = x+22√(x2+4x+1) - 32 log|x+2 + √(x2+4x+1)| + C

प्रश्न 5: ∫ √(1 - 4x - x2) dx

हल: 1 - 4x - x2 = 5 - (x+2)2

मान लीजिए x+2 = t ⇒ dx = dt

= ∫ √((√5)2 - t2) dt

उत्तर: = x+22√(1-4x-x2) + 52 sin-1(x+2√5) + C
