प्रश्नावली 9.4 (समघातीय अवकल समीकरण)

प्रश्न 1: (x2 + xy) dy = (x2 + y2) dx

हल: dydx = x2 + y2x2 + xy

यह एक समघातीय अवकल समीकरण है। मान लीजिए y = vx ⇒ dydx = v + xdvdx

v + xdvdx = 1 + v21 + v

xdvdx = 1 + v2 - v - v21 + v = 1 - v1 + v

∫ 1 + v1 - v dv = ∫ dxx

∫ (-1 + 21 - v) dv = log|x| + C

-v - 2log|1 - v| = log|x| + C

-yx - 2log|x - yx| = log|x| + C

-yx - 2log|x - y| + 2log|x| = log|x| + C

-yx - 2log|x - y| + log|x| = C

log|x| - 2log|x - y| = C + yx

उत्तर: (x - y)2 = Cx e-y/x (या y/x + 2log|x - y| - log|x| = C)

प्रश्न 2: y' = x + yx

हल: dydx = 1 + yx

मान लीजिए y = vx ⇒ dydx = v + xdvdx

v + xdvdx = 1 + v ⇒ xdvdx = 1

∫ dv = ∫ dxx ⇒ v = log|x| + C

उत्तर: y = x log|x| + Cx

प्रश्न 3: (x - y) dy - (x + y) dx = 0

हल: dydx = x + yx - y

y = vx ⇒ v + xdvdx = 1 + v1 - v

xdvdx = 1 + v1 - v - v = 1 + v - v + v21 - v = 1 + v21 - v

∫ 1 - v1 + v2 dv = ∫ dxx

tan-1v - 12log(1 + v2) = log|x| + C

उत्तर: 2tan-1(yx) - log(x2 + y2) = C

प्रश्न 4: (x2 - y2) dx + 2xy dy = 0

हल: dydx = y2 - x22xy

y = vx ⇒ v + xdvdx = v2 - 12v

xdvdx = v2 - 1 - 2v22v = -1 + v22v

∫ 2v1 + v2 dv = -∫ dxx

log(1 + v2) = -log|x| + C ⇒ log(x2 + y2x2) + log|x| = C

उत्तर: x2 + y2 = Cx

प्रश्न 5: x2dydx = x2 - 2y2 + xy

हल: dydx = 1 - 2(yx)2 + yx

y = vx ⇒ v + xdvdx = 1 - 2v2 + v

xdvdx = 1 - 2v2 ⇒ ∫ dv1 - 2v2 = ∫ dxx

12√2 log|1 + √2v1 - √2v| = log|x| + C

उत्तर: 12√2 log|x + √2yx - √2y| = log|x| + C

प्रश्न 6: x dy - y dx = √(x2 + y2) dx

हल: xdydx - y = √(x2 + y2) ⇒ dydx - yx = 1x√(x2 + y2)

y = vx ⇒ v + xdvdx - v = 1x√(x2 + v2x2) = √(1 + v2)

xdvdx = √(1 + v2) ⇒ ∫ dv√(1 + v2) = ∫ dxx

log|v + √(1 + v2)| = log|x| + C ⇒ v + √(1 + v2) = Cx

उत्तर: y + √(x2 + y2) = Cx2

प्रश्न 7: {x cos(y/x) + y sin(y/x)} y dx = {y sin(y/x) - x cos(y/x)} x dy

हल: दोनों पक्षों को x2 से भाग देने पर और y = vx रखने पर:

(cos v + v sin v) v dx = (v sin v - cos v) (v dx + x dv)

v cos v dx + v2 sin v dx = v2 sin v dx + v x sin v dv - v cos v dx - x cos v dv

2v cos v dx = x(v sin v - cos v) dv

2dxx = v sin v - cos vv cos v dv = (tan v - 1v) dv

2 log|x| = -log|cos v| - log|v| + C ⇒ log(x2 v cos v) = C

उत्तर: xy cos(y/x) = C

प्रश्न 8: xdydx - y + x sin(y/x) = 0

हल: dydx = yx - sin(yx)

y = vx ⇒ v + xdvdx = v - sin v ⇒ xdvdx = -sin v

∫ cosec v dv = -∫ dxx ⇒ log|tan(v/2)| = -log|x| + C

उत्तर: x = C ecos(y/x)

प्रश्न 9: y dx + x log(y/x) dy - 2x dy = 0

हल: dxdy = 2x - x log(y/x)y

मान लीजिए x = vy ⇒ dxdy = v + ydvdy

v + ydvdy = 2v - v log v ⇒ ydvdy = v(1 - log v)

∫ dvv(1 - log v) = ∫ dyy. मान लीजिए 1 - log v = t ⇒ -1v dv = dt

-log|t| = log|y| + C ⇒ log|y(1 - log v)| = C'

उत्तर: y(1 - log(yx)) = C

प्रश्न 10: {1 + ex/y} dx + ex/y {1 - x/y} dy = 0

हल: मान लीजिए x = vy ⇒ dx = v dy + y dv

(1 + ev)(v dy + y dv) + ev(1 - v) dy = 0

(v + v ev + ev - v ev) dy + y(1 + ev) dv = 0

(v + ev) dy + y(1 + ev) dv = 0

∫ dyy + ∫ 1 + evv + ev dv = 0

log|y| + log|v + ev| = log C ⇒ y(v + ev) = C

उत्तर: x + y ex/y = C

प्रश्न 11: (x + y) dy + (x - y) dx = 0; y = 1 यदि x = 1

हल: dydx = y - xy + x

y = vx ⇒ v + xdvdx = v - 1v + 1

xdvdx = v - 1 - v2 - vv + 1 = -v2 + 1v + 1

∫ v + 1v2 + 1 dv = -∫ dxx

12 log(v2 + 1) + tan-1v = -log|x| + C

log(x2 + y2) + 2tan-1(y/x) = C'. (1, 1) रखने पर: log 2 + 2(π/4) = C'

उत्तर: log(x2 + y2) + 2tan-1(y/x) = log 2 + π2

प्रश्न 12: x2 dy + (xy + y2) dx = 0; y = 1 यदि x = 1

हल: dydx = -(xy + y2x2) = -yx - (yx)2

y = vx ⇒ v + xdvdx = -v - v2 ⇒ xdvdx = -v(2 + v)

∫ dvv(v + 2) = -∫ dxx ⇒ 12 log|vv + 2| = -log|x| + C

log|y/xy/x + 2| = -2log|x| + C' ⇒ yy + 2x = C x-2

(1, 1) रखने पर: 13 = C

उत्तर: x2y = 13(y + 2x) ⇒ 3x2y = y + 2x

प्रश्न 13: [x sin2(y/x) - y] dx + x dy = 0; y = π/4 यदि x = 1

हल: dydx = yx - sin2(y/x)

y = vx ⇒ v + xdvdx = v - sin2v ⇒ xdvdx = -sin2v

∫ cosec2v dv = -∫ dxx ⇒ -cot v = -log|x| + C ⇒ cot v = log|x| + C'

x=1, y=π/4 रखने पर: cot(π/4) = log 1 + C' ⇒ C'=1

उत्तर: cot(y/x) = log|x| + 1 ⇒ y = x cot-1(log|x| + 1)

प्रश्न 14: dydx - yx + cosec(y/x) = 0; y = 0 यदि x = 1

हल: dydx = yx - cosec(y/x)

y = vx ⇒ v + xdvdx = v - cosec v ⇒ xdvdx = -cosec v

∫ sin v dv = -∫ dxx ⇒ -cos v = -log|x| + C ⇒ cos v = log|x| + C'

x=1, y=0 रखने पर: cos 0 = 0 + C' ⇒ C'=1

उत्तर: cos(y/x) = log|x| + 1 ⇒ y = x cos-1(log|x| + 1)

प्रश्न 15: 2xy + y2 - 2x2dydx = 0; y = 2 यदि x = 1

हल: dydx = yx + 12(yx)2

y = vx ⇒ v + xdvdx = v + v22 ⇒ xdvdx = v22

∫ 2v2 dv = ∫ dxx ⇒ -2v = log|x| + C ⇒ -2xy = log|x| + C

x=1, y=2 रखने पर: -1 = 0 + C ⇒ C = -1

उत्तर: 2xy = 1 - log|x| ⇒ y = 2x1 - log|x|

प्रश्न 16: dxdy = h(xy) के रूप वाले समघातीय अवकल समीकरण को हल करने के लिए निम्नलिखित में से कौन सा प्रतिस्थापन किया जाता है:

(A) y = vx    (B) v = yx    (C) x = vy    (D) x = v

हल: जब समीकरण dx/dy के रूप में हो, तो x = vy प्रतिस्थापन उपयुक्त होता है।

उत्तर: विकल्प (C) सही है।

प्रश्न 17: निम्नलिखित में से कौन सा समघातीय अवकल समीकरण है?

प्रश्नावली 9.5 (रैखिक अवकल समीकरण)

प्रश्न 1: dydx + 2y = sin x

हल: यह dy/dx + Py = Q के रूप में है। यहाँ P = 2, Q = sin x

I.F. = e∫ 2 dx = e2x

y · e2x = ∫ e2x sin x dx + C = e2x5(2sin x - cos x) + C

उत्तर: y = 15(2sin x - cos x) + C e-2x

प्रश्न 2: dydx + 3y = e-2x

हल: P = 3, Q = e-2x

I.F. = e∫ 3 dx = e3x

y · e3x = ∫ e3x · e-2x dx = ∫ ex dx = ex + C

उत्तर: y = e-2x + C e-3x

प्रश्न 3: dydx + yx = x2

हल: P = 1/x, Q = x2

I.F. = e∫ 1/x dx = elog x = x

y · x = ∫ x · x2 dx = ∫ x3 dx = x44 + C

उत्तर: y = x34 + Cx

प्रश्न 4: dydx + (sec x)y = tan x

हल: P = sec x, Q = tan x

I.F. = e∫ sec x dx = elog(sec x + tan x) = sec x + tan x

y(sec x + tan x) = ∫ tan x(sec x + tan x) dx = ∫ (sec x tan x + tan2x) dx

= ∫ (sec x tan x + sec2x - 1) dx = sec x + tan x - x + C

उत्तर: y = 1 - xsec x + tan x + Csec x + tan x

प्रश्न 5: cos2xdydx + y = tan x

हल: dydx + y sec2x = tan x sec2x

P = sec2x, Q = tan x sec2x

I.F. = e∫ sec2x dx = etan x

y · etan x = ∫ tan x sec2x etan x dx. मान लीजिए t = tan x ⇒ dt = sec2x dx

= ∫ t et dt = t et - et = etan x(tan x - 1) + C

उत्तर: y = tan x - 1 + C e-tan x

प्रश्न 6: xdydx + 2y = x2 log x

हल: dydx + 2xy = x log x

P = 2/x, Q = x log x. I.F. = e∫ 2/x dx = x2

y · x2 = ∫ x3 log x dx = log x (x44) - ∫ x44 · 1x dx = x44 log x - x416 + C

उत्तर: y = x24 log x - x216 + Cx2

प्रश्न 7: x log xdydx + y = 2x log x

हल: dydx + 1x log xy = 2x2

P = 1/(x log x), Q = 2/x2. I.F. = e∫ 1/(x log x) dx = elog(log x) = log x

y log x = ∫ 2x2 log x dx = 2 [log x (-1x) - ∫ 1x(-1x) dx]

= -2x log x - 2x + C = -2x(log x + 1) + C

उत्तर: y = -2x - 2x log x + Clog x

प्रश्न 8: (1 + x2) dy + 2xy dx = cot x dx

हल: dydx + 2x1 + x2y = cot x1 + x2

P = 2x/(1+x2), Q = cot x/(1+x2). I.F. = e∫ 2x/(1+x2) dx = 1 + x2

y(1 + x2) = ∫ cot x dx = log|sin x| + C

उत्तर: y = log|sin x| + C1 + x2

प्रश्न 9: xdydx + y - x + xy cot x = 0

हल: dydx + y(1x + cot x) = 1

P = 1/x + cot x, Q = 1. I.F. = e∫ (1/x + cot x) dx = elog x + log(sin x) = x sin x

y(x sin x) = ∫ x sin x dx = -x cos x + sin x + C

उत्तर: y = -x cos x + sin x + Cx sin x

प्रश्न 10: (x + y)dydx = 1

हल: dxdy - x = y

P = -1, Q = y. I.F. = e∫ -1 dy = e-y

x e-y = ∫ y e-y dy = -y e-y - e-y + C

उत्तर: x = -y - 1 + C ey

प्रश्न 11: y dx + (x - y2) dy = 0

हल: dxdy + 1yx = y

P = 1/y, Q = y. I.F. = e∫ 1/y dy = y

xy = ∫ y2 dy = y33 + C

उत्तर: xy = y33 + C

प्रश्न 12: (x + 3y2)dydx = y

हल: dxdy - xy = 3y

P = -1/y, Q = 3y. I.F. = e∫ -1/y dy = 1/y

x · 1y = ∫ 3y · 1y dy = ∫ 3 dy = 3y + C

उत्तर: x = 3y2 + Cy

प्रश्न 13: dydx + 2y tan x = sin x; y = 0 यदि x = π/3

हल: P = 2 tan x, Q = sin x. I.F. = e∫ 2 tan x dx = sec2x

y sec2x = ∫ sin x sec2x dx = ∫ tan x sec x dx = sec x + C

x=π/3, y=0 रखने पर: 0 = sec(π/3) + C ⇒ C = -2

उत्तर: y = cos x - 2 cos2x

प्रश्न 14: (1 + x2)dydx + 2xy = 11 + x2; y = 0 यदि x = 1

हल: dydx + 2x1 + x2y = 1(1 + x2)2

I.F. = e∫ 2x/(1+x2) dx = 1 + x2

y(1 + x2) = ∫ 11 + x2 dx = tan-1x + C

x=1, y=0 रखने पर: 0 = π/4 + C ⇒ C = -π/4

उत्तर: y = tan-1x - π/41 + x2

प्रश्न 15: dydx - 3y cot x = sin 2x; y = 2 यदि x = π/2

हल: P = -3 cot x, Q = sin 2x. I.F. = e∫ -3 cot x dx = e-3log(sin x) = cosec3x

y cosec3x = ∫ sin 2x cosec3x dx = ∫ 2sin x cos x cosec3x dx = ∫ 2cot x cosec x dx = -2cosec x + C

x=π/2, y=2 रखने पर: 2(1) = -2(1) + C ⇒ C=4

उत्तर: y = -2sin2x + 4sin3x

प्रश्न 16: मूल बिंदु से गुजरने वाले एक वक्र का समीकरण ज्ञात कीजिए यदि इस वक्र के किसी बिंदु (x, y) पर स्पर्श रेखा की प्रवणता उस बिंदु के निर्देशांकों के योग के बराबर है।

हल: dydx = x + y ⇒ dydx - y = x

P = -1, Q = x. I.F. = e-x

y e-x = ∫ x e-x dx = -x e-x - e-x + C

(0,0) से गुजरता है: 0 = -1 + C ⇒ C=1

उत्तर: y = ex - x - 1

प्रश्न 17: बिंदु (0, 2) से गुजरने वाले वक्र का समीकरण ज्ञात कीजिए यदि इस वक्र के किसी बिंदु के निर्देशांकों का योग उस बिंदु पर खींची गई स्पर्श रेखा की प्रवणता के परिमाण से 5 अधिक है।

हल: x + y = dydx + 5 ⇒ dydx - y = x - 5

P = -1, Q = x - 5. I.F. = e-x

y e-x = ∫ (x - 5)e-x dx = -(x - 4)e-x + C

(0, 2) से गुजरता है: 2 = 4 + C ⇒ C = -2

उत्तर: y = 4 - x - 2ex

प्रश्न 18: अवकल समीकरण xdydx - y = 2x2 का समाकलन गुणक है:

(A) e-x    (B) e-y    (C) 1/x    (D) x

हल: dydx - 1xy = 2x. यहाँ P = -1/x

I.F. = e∫ -1/x dx = e-log x = 1/x

उत्तर: विकल्प (C) सही है।

प्रश्न 19: अवकल समीकरण (1 - y2)dxdy + yx = ay का समाकलन गुणक है:

(A) 1y2-1    (B) 1√(y2-1)    (C) 11-y2    (D) 1√(1-y2)

हल: dxdy + y1 - y2x = ay1 - y2. P = y/(1-y2)

I.F. = e∫ y/(1-y2) dy = e-1/2 log(1-y2) = 1√(1-y2)

उत्तर: विकल्प (D) सही है।
