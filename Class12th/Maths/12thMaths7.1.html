प्रश्नावली 7.1 (निरीक्षण विधि द्वारा प्रतिअवकलज)

प्रश्न 1: sin 2x का प्रतिअवकलज ज्ञात कीजिए।

हल: हम जानते हैं कि ddx (cos 2x) = -2 sin 2x

अतः ddx (-12 cos 2x) = sin 2x

उत्तर: ∫ sin 2x dx = -12 cos 2x + C

प्रश्न 2: cos 3x का प्रतिअवकलज ज्ञात कीजिए।

हल: हम जानते हैं कि ddx (sin 3x) = 3 cos 3x

अतः ddx (13 sin 3x) = cos 3x

उत्तर: ∫ cos 3x dx = 13 sin 3x + C

प्रश्न 3: e2x का प्रतिअवकलज ज्ञात कीजिए।

हल: हम जानते हैं कि ddx (e2x) = 2e2x

अतः ddx (12 e2x) = e2x

उत्तर: ∫ e2x dx = 12 e2x + C

प्रश्न 4: (ax + b)2 का प्रतिअवकलज ज्ञात कीजिए।

हल: हम जानते हैं कि ddx (ax + b)3 = 3a(ax + b)2

अतः ddx [13a (ax + b)3] = (ax + b)2

उत्तर: ∫ (ax + b)2 dx = 13a (ax + b)3 + C

प्रश्न 5: sin 2x - 4e3x का प्रतिअवकलज ज्ञात कीजिए।

हल: ∫ (sin 2x - 4e3x) dx = ∫ sin 2x dx - 4∫ e3x dx

= -12 cos 2x - 4(13 e3x) + C

उत्तर: = -12 cos 2x - 43 e3x + C

उत्तर: = 43 e3x + x + C
