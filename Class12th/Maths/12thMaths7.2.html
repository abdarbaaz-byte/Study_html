प्रश्नावली 7.3 (त्रिकोणमितीय सर्वसमिकाओं का उपयोग)

प्रश्न 1: ∫ sin2(2x + 5) dx

हल: सर्वसमिका sin2θ = 1 - cos 2θ2 का प्रयोग करते हुए:

= ∫ 1 - cos(4x + 10)2 dx

= 12 ∫ 1 dx - 12 ∫ cos(4x + 10) dx

= 12x - 12 · sin(4x + 10)4 + C

उत्तर: = x2 - 18 sin(4x + 10) + C

प्रश्न 2: ∫ sin 3x cos 4x dx

हल: सर्वसमिका 2 sin A cos B = sin(A+B) + sin(A-B) का प्रयोग करते हुए:

= 12 ∫ [sin(7x) + sin(-x)] dx

= 12 ∫ [sin 7x - sin x] dx

= 12 [-cos 7x7 + cos x] + C

उत्तर: = -114 cos 7x + 12 cos x + C

प्रश्न 3: ∫ cos 2x cos 4x cos 6x dx

हल: पहले पहले दो पदों पर सूत्र लगाते हैं: 2 cos A cos B = cos(A+B) + cos(A-B)

= 12 ∫ (cos 6x + cos 2x) cos 6x dx

= 12 ∫ (cos2 6x + cos 2x cos 6x) dx

अब cos2 6x = (1 + cos 12x)/2 और 2 cos 2x cos 6x = cos 8x + cos 4x का प्रयोग करते हैं:

= 12 ∫ [(1 + cos 12x2) + (cos 8x + cos 4x2)] dx

= 14 ∫ (1 + cos 12x + cos 8x + cos 4x) dx

उत्तर: = 14 [x + sin 12x12 + sin 8x8 + sin 4x4] + C

प्रश्न 4: ∫ sin3(2x + 1) dx

हल: सूत्र sin 3θ = 3 sin θ - 4 sin3θ से, sin3θ = 3 sin θ - sin 3θ4

= 14 ∫ [3 sin(2x + 1) - sin(6x + 3)] dx

= 34 (-cos(2x + 1)2) - 14 (-cos(6x + 3)6) + C

उत्तर: = -38 cos(2x + 1) + 124 cos(6x + 3) + C

प्रश्न 5: ∫ sin3x cos3x dx

हल: = ∫ (sin x cos x)3 dx = ∫ (sin 2x2)3 dx

= 18 ∫ sin3 2x dx

प्रश्न 4 की तरह हल करने पर: = 18 ∫ [3 sin 2x - sin 6x4] dx

= 332 (-cos 2x2) - 132 (-cos 6x6) + C

उत्तर: = -364 cos 2x + 1192 cos 6x + C

प्रश्न 6: ∫ sin x sin 2x sin 3x dx

हल: = 12 ∫ (cos x - cos 3x) sin 3x dx

= 12 ∫ [sin 3x cos x - sin 3x cos 3x] dx

= 12 ∫ [sin 4x + sin 2x2] dx - 12 ∫ [sin 6x2] dx

= 14 (-cos 4x4 - cos 2x2) + 112 cos 6x + C

उत्तर: = -116 cos 4x - 18 cos 2x + 112 cos 6x + C

प्रश्न 7: ∫ sin 4x sin 8x dx

हल: 2 sin A sin B = cos(A-B) - cos(A+B)

= 12 ∫ [cos 4x - cos 12x] dx

= 12 [sin 4x4 - sin 12x12] + C

उत्तर: = 18 sin 4x - 124 sin 12x + C

प्रश्न 8: ∫ 1 - cos x1 + cos x dx

हल: = ∫ 2 sin2(x/2)2 cos2(x/2) dx = ∫ tan2(x/2) dx

= ∫ [sec2(x/2) - 1] dx

= tan(x/2)1/2 - x + C

उत्तर: = 2 tan(x/2) - x + C

प्रश्न 9: ∫ cos x1 + cos x dx

हल: = ∫ 1 + cos x - 11 + cos x dx = ∫ (1 - 11 + cos x) dx

= ∫ dx - ∫ 12 cos2(x/2) dx

= x - 12 ∫ sec2(x/2) dx

= x - 12 [tan(x/2)1/2] + C

उत्तर: = x - tan(x/2) + C

प्रश्न 10: ∫ sin4x dx

हल: = ∫ (1 - cos 2x2)2 dx = 14 ∫ (1 - 2cos 2x + cos2 2x) dx

= 14 ∫ [1 - 2cos 2x + 1 + cos 4x2] dx

= 14 ∫ [32 - 2cos 2x + 12cos 4x] dx

= 14 [3x2 - sin 2x + sin 4x8] + C

उत्तर: = 3x8 - 14 sin 2x + 132 sin 4x + C

प्रश्न 11: ∫ cos4 2x dx

हल: प्रश्न 10 की तरह cos2θ = 1 + cos 2θ2 का प्रयोग करते हैं:

= ∫ (1 + cos 4x2)2 dx = 14 ∫ (1 + 2cos 4x + cos2 4x) dx

= 14 ∫ [1 + 2cos 4x + 1 + cos 8x2] dx

= 14 [3x2 + sin 4x2 + sin 8x16] + C

उत्तर: = 3x8 + 18 sin 4x + 164 sin 8x + C

प्रश्न 12: ∫ sin2x1 + cos x dx

हल: = ∫ 1 - cos2x1 + cos x dx = ∫ (1 - cos x)(1 + cos x)1 + cos x) dx

= ∫ (1 - cos x) dx

उत्तर: = x - sin x + C

प्रश्न 13: ∫ cos 2x - cos 2αcos x - cos α dx

हल: सूत्र का प्रयोग: cos C - cos D = -2 sin(C+D2) sin(C-D2)

= ∫ -2 sin(x + α) sin(x - α)-2 sin(x + α2) sin(x - α2) dx

= ∫ 2 sin(x + α2) cos(x + α2) · 2 sin(x - α2) cos(x - α2)2 sin(x + α2) sin(x - α2) dx

= 2 ∫ cos(x + α2) cos(x - α2) dx = ∫ (cos x + cos α) dx

उत्तर: = sin x + x cos α + C

प्रश्न 14: ∫ cos x - sin x1 + sin 2x dx

हल: 1 + sin 2x = sin2x + cos2x + 2 sin x cos x = (sin x + cos x)2

= ∫ cos x - sin x(cos x + sin x)2 dx

मान लीजिए cos x + sin x = t, तो (-sin x + cos x) dx = dt

= ∫ 1t2 dt = -1t + C

उत्तर: = -1sin x + cos x + C

प्रश्न 15: ∫ tan3 2x sec 2x dx

हल: = ∫ (sec2 2x - 1) sec 2x tan 2x dx

मान लीजिए sec 2x = t, तो 2 sec 2x tan 2x dx = dt

= 12 ∫ (t2 - 1) dt = 12 (t33 - t) + C

उत्तर: = 16 sec3 2x - 12 sec 2x + C

प्रश्न 16: ∫ tan4x dx

हल: = ∫ tan2x · tan2x dx = ∫ tan2x (sec2x - 1) dx

= ∫ tan2x sec2x dx - ∫ tan2x dx

= ∫ tan2x sec2x dx - ∫ (sec2x - 1) dx

= tan3x3 - tan x + x + C

प्रश्न 17: ∫ sin3x + cos3xsin2x cos2x dx

हल: = ∫ (sin3xsin2x cos2x) dx + ∫ (cos3xsin2x cos2x) dx

= ∫ sin xcos2x dx + ∫ cos xsin2x dx

= ∫ sec x tan x dx + ∫ cosec x cot x dx

उत्तर: = sec x - cosec x + C

प्रश्न 18: ∫ cos 2x + 2sin2xcos2x dx

हल: cos 2x = 1 - 2sin2x रखने पर:

= ∫ 1 - 2sin2x + 2sin2xcos2x dx = ∫ 1cos2x dx

= ∫ sec2x dx

उत्तर: = tan x + C

प्रश्न 19: ∫ 1sin x cos3x dx

हल: अंश और हर को cos4x से भाग देने पर:

= ∫ sec4xtan x dx = ∫ sec2x · sec2xtan x dx

= ∫ (1 + tan2x) sec2xtan x dx

मान लीजिए tan x = t, तो sec2x dx = dt

= ∫ 1 + t2t dt = ∫ (1t + t) dt

= log|t| + t22 + C

उत्तर: = log|tan x| + 12 tan2x + C

प्रश्न 20: ∫ cos 2x(cos x + sin x)2 dx

हल: = ∫ cos2x - sin2x(cos x + sin x)2 dx

= ∫ (cos x - sin x)(cos x + sin x)(cos x + sin x)2 dx

= ∫ cos x - sin xcos x + sin x dx

मान लीजिए cos x + sin x = t, तो (-sin x + cos x) dx = dt

= ∫ 1t dt = log|t| + C

उत्तर: = log|sin x + cos x| + C

प्रश्न 21: ∫ sin-1(cos x) dx

हल: हम जानते हैं कि sin-1(cos x) = sin-1(sin(π/2 - x)) = π/2 - x

= ∫ (π/2 - x) dx

उत्तर: = π2x - x22 + C

प्रश्न 22: ∫ 1cos(x - a) cos(x - b) dx

हल: अंश और हर को sin(a - b) से गुणा करने पर:

= 1sin(a-b) ∫ sin(a-b)cos(x - a) cos(x - b) dx

= 1sin(a-b) ∫ sin[(x-b) - (x-a)]cos(x - a) cos(x - b) dx

= 1sin(a-b) ∫ [tan(x-b) - tan(x-a)] dx

= 1sin(a-b) [-log|cos(x-b)| + log|cos(x-a)|] + C

उत्तर: = 1sin(a-b) log|cos(x-a)cos(x-b)| + C

प्रश्न 23: ∫ sin2x - cos2xsin2x cos2x dx बराबर है:

(A) tan x + cot x + C   (B) tan x + cosec x + C   (C) -tan x + cot x + C   (D) tan x + sec x + C

हल: = ∫ (sin2xsin2x cos2x - cos2xsin2x cos2x) dx

= ∫ (1cos2x - 1sin2x) dx = ∫ (sec2x - cosec2x) dx

= tan x - (-cot x) + C = tan x + cot x + C

उत्तर: विकल्प (A) सही है।

प्रश्न 24: ∫ ex(1 + x)cos2(exx) dx बराबर है:

(A) -cot(exx) + C   (B) tan(xex) + C   (C) tan(ex) + C   (D) cot(ex) + C

हल: मान लीजिए x ex = t, तो (x ex + ex) dx = dt ⇒ ex(x+1) dx = dt

= tan(x ex) + C

उत्तर: विकल्प (B) सही है।
