प्रश्न 3: यदि P(A) = 0.8, P(B) = 0.5 और P(B|A) = 0.4 ज्ञात कीजिए (i) P(A ∩ B) (ii) P(A|B) (iii) P(A ∪ B)

हल:

(i) P(B|A) = P(A ∩ B)P(A) ⇒ P(A ∩ B) = P(B|A) · P(A) = 0.4 × 0.8 = 0.32

(ii) P(A|B) = P(A ∩ B)P(B) = 0.320.5 = 0.64

(iii) P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 0.8 + 0.5 - 0.32 = 0.98
