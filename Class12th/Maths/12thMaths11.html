प्रश्न 1: यदि एक रेखा x, y और z-अक्ष के साथ क्रमशः 90°, 135°, 45° के कोण बनाती है तो इसकी दिक्-कोसाइन ज्ञात कीजिए।

हल: दिया गया है, α = 90°, β = 135°, γ = 45°

दिक्-कोसाइन: l = cos α, m = cos β, n = cos γ

l = cos 90° = 0

m = cos 135° = -1√2

n = cos 45° = 1√2

उत्तर: 0, -1√2, 1√2

प्रश्न 2: एक रेखा की दिक्-कोसाइन ज्ञात कीजिए जो निर्देशांक्षों के साथ समान कोण बनाती है।

हम जानते हैं कि l2 + m2 + n2 = 1

cos α = ±1√3

उत्तर: ±1√3, ±1√3, ±1√3
