प्रश्नावली 12.1 (आलेखीय विधि से हल)

प्रश्न 1: निम्न अवरोधों के अंतर्गत Z = 3x + 4y का अधिकतमीकरण कीजिए: x + y ≤ 4, x ≥ 0, y ≥ 0

हल: दिए गए अवरोध हैं:

x + y ≤ 4 ...(1)

x ≥ 0, y ≥ 0 ...(2)

रेखा x + y = 4 बिंदुओं (4, 0) और (0, 4) से गुजरती है।

असमिका x + y ≤ 4 मूल बिंदु (0,0) को शामिल करती है। अतः सुसंगत क्षेत्र OAB (परिबद्ध) है, जहाँ O(0,0), A(4,0) और B(0,4) हैं।

कोनीय बिंदुओं पर Z = 3x + 4y का मान:

O(0, 0) पर: Z = 3(0) + 4(0) = 0

A(4, 0) पर: Z = 3(4) + 4(0) = 12

B(0, 4) पर: Z = 3(0) + 4(4) = 16

उत्तर: Z का अधिकतम मान 16 है, जो बिंदु (0, 4) पर प्राप्त होता है।

प्रश्न 2: निम्न अवरोधों के अंतर्गत Z = -3x + 4y का न्यूनतमीकरण कीजिए: x + 2y ≤ 8, 3x + 2y ≤ 12, x ≥ 0, y ≥ 0

हल: दिए गए अवरोध हैं:

x + 2y ≤ 8 ...(1)

3x + 2y ≤ 12 ...(2)

x ≥ 0, y ≥ 0 ...(3)

रेखाओं के प्रतिच्छेदन बिंदु ज्ञात करते हैं: x + 2y = 8 और 3x + 2y = 12. घटाने पर 2x = 4 ⇒ x = 2, y = 3

सुसंगत क्षेत्र परिबद्ध है जिसके कोनीय बिंदु हैं: O(0,0), A(4,0), B(2,3), C(0,4).

Z = -3x + 4y का मान:

O(0, 0) पर: Z = 0

A(4, 0) पर: Z = -12

B(2, 3) पर: Z = -6 + 12 = 6

C(0, 4) पर: Z = 16

उत्तर: Z का न्यूनतम मान -12 है, जो बिंदु (4, 0) पर प्राप्त होता है।

प्रश्न 3: निम्न अवरोधों के अंतर्गत Z = 5x + 3y का अधिकतमीकरण कीजिए: 3x + 5y ≤ 15, 5x + 2y ≤ 10, x ≥ 0, y ≥ 0

हल: दिए गए अवरोध हैं:

3x + 5y ≤ 15 ...(1)

5x + 2y ≤ 10 ...(2)

x ≥ 0, y ≥ 0 ...(3)

रेखाओं के प्रतिच्छेदन बिंदु: 3x + 5y = 15 और 5x + 2y = 10

पहले को 2 से और दूसरे को 5 से गुणा करने पर: 6x + 10y = 30, 25x + 10y = 50. घटाने पर: 19x = 20 ⇒ x = 2019, y = 4519

सुसंगत क्षेत्र के कोनीय बिंदु: O(0,0), A(2,0), B(2019, 4519), C(0,3)

Z = 5x + 3y का मान:

O(0, 0): Z = 0

A(2, 0): Z = 10

C(0, 3): Z = 9

B(2019, 4519): Z = 10019 + 13519 = 23519

उत्तर: Z का अधिकतम मान 23519 है, जो बिंदु (2019, 4519) पर प्राप्त होता है।

प्रश्न 4: निम्न अवरोधों के अंतर्गत Z = 3x + 5y का न्यूनतमीकरण कीजिए: x + 3y ≥ 3, x + y ≥ 2, x, y ≥ 0

हल: दिए गए अवरोध हैं:

x + 3y ≥ 3 ...(1)

x + y ≥ 2 ...(2)

x, y ≥ 0 ...(3)

रेखाओं के प्रतिच्छेदन बिंदु: x + 3y = 3 और x + y = 2. घटाने पर: 2y = 1 ⇒ y = 12, x = 32

सुसंगत क्षेत्र (अपरिबद्ध) के कोनीय बिंदु: A(32, 12), B(3,0), C(0,2)

Z = 3x + 5y का मान:

A(32, 12): Z = 92 + 52 = 7

B(3, 0): Z = 9

C(0, 2): Z = 10

उत्तर: Z का न्यूनतम मान 7 है, जो बिंदु (32, 12) पर प्राप्त होता है।

प्रश्न 5: निम्न अवरोधों के अंतर्गत Z = 3x + 2y का न्यूनतमीकरण कीजिए: x + 2y ≤ 10, 3x + y ≤ 15, x, y ≥ 0

हल: दिए गए अवरोध हैं:

x + 2y ≤ 10 ...(1)

3x + y ≤ 15 ...(2)

x, y ≥ 0 ...(3)

रेखाओं के प्रतिच्छेदन बिंदु: x + 2y = 10 और 3x + y = 15. पहले को 3 से गुणा करने पर: 3x + 6y = 30. दूसरे से घटाने पर: 5y = 15 ⇒ y = 3, x = 4

सुसंगत क्षेत्र (परिबद्ध) के कोनीय बिंदु: O(0,0), A(5,0), B(4,3), C(0,5)

Z = 3x + 2y का मान:

O(0, 0): Z = 0

A(5, 0): Z = 15

B(4, 3): Z = 12 + 6 = 18

C(0, 5): Z = 10

उत्तर: यदि प्रश्न में "न्यूनतमीकरण" (Minimize) है, तो Z का न्यूनतम मान 0 है, जो बिंदु (0, 0) पर प्राप्त होता है। (यदि यह "अधिकतमीकरण" है, तो अधिकतम मान 18 है, जो बिंदु (4, 3) पर प्राप्त होता है।)

प्रश्न 6: निम्न अवरोधों के अंतर्गत Z = x + 2y का न्यूनतमीकरण कीजिए: 2x + y ≥ 3, x + 2y ≥ 6, x, y ≥ 0. दिखाइए कि Z का न्यूनतम मान दो बिंदुओं से अधिक बिंदुओं पर घटित होता है।

हल: दिए गए अवरोध हैं:

2x + y ≥ 3 ...(1)

x + 2y ≥ 6 ...(2)

x, y ≥ 0 ...(3)

रेखाओं के प्रतिच्छेदन बिंदु: 2x + y = 3 और x + 2y = 6. पहले से y = 3 - 2x रखने पर: x + 2(3-2x) = 6 ⇒ x + 6 - 4x = 6 ⇒ -3x = 0 ⇒ x = 0, y = 3

सुसंगत क्षेत्र (अपरिबद्ध) के कोनीय बिंदु: A(0,3), B(6,0)

Z = x + 2y का मान:

A(0, 3): Z = 0 + 6 = 6

B(6, 0): Z = 6 + 0 = 6

चूँकि बिंदु A और B पर Z का मान समान (6) है, और उद्देश्य फलन \(Z = x + 2y\) की रेखा \(x + 2y = 6\) के समांतर है, इसलिए रेखाखंड AB पर स्थित प्रत्येक बिंदु पर Z का मान 6 (न्यूनतम) होगा।

उत्तर: Z का न्यूनतम मान 6 है, जो रेखाखंड AB के सभी बिंदुओं (अनंत बिंदुओं) पर प्राप्त होता है।

प्रश्न 7: निम्न अवरोधों के अंतर्गत Z = 5x + 10y का न्यूनतमीकरण तथा अधिकतमीकरण कीजिए: x + 2y ≤ 120, x + y ≥ 60, x - 2y ≥ 0, x, y ≥ 0

हल: दिए गए अवरोध हैं:

x + 2y ≤ 120 ...(1)

x + y ≥ 60 ...(2)

x - 2y ≥ 0 ...(3)

x, y ≥ 0 ...(4)

प्रतिच्छेदन बिंदु:

P1: x+y=60 और x-2y=0 ⇒ x=2y ⇒ 2y+y=60 ⇒ y=20, x=40 (बिंदु: 40, 20)

P2: x+2y=120 और x-2y=0 ⇒ 2x=120 ⇒ x=60, y=30 (बिंदु: 60, 30)

P3: x+y=60 और y=0 ⇒ x=60 (बिंदु: 60, 0)

सुसंगत क्षेत्र के कोनीय बिंदु: A(60,0), B(60,30), C(40,20), D(0,60)

Z = 5x + 10y का मान:

A(60, 0): Z = 300

B(60, 30): Z = 300 + 300 = 600

C(40, 20): Z = 200 + 200 = 400

D(0, 60): Z = 0 + 600 = 600

उत्तर: न्यूनतम मान 300 है (बिंदु 60, 0 पर) और अधिकतम मान 600 है, जो बिंदु (60, 30) और (0, 60) दोनों पर प्राप्त होता है।

प्रश्न 8: निम्न अवरोधों के अंतर्गत Z = x + 2y का न्यूनतमीकरण तथा अधिकतमीकरण कीजिए: x + 2y ≥ 100, 2x - y ≤ 0, 2x + y ≤ 200, x, y ≥ 0

हल: दिए गए अवरोध हैं:

x + 2y ≥ 100 ...(1)

2x - y ≤ 0 ...(2)

2x + y ≤ 200 ...(3)

x, y ≥ 0 ...(4)

प्रतिच्छेदन बिंदु:

P1: 2x-y=0 और x+2y=100 ⇒ y=2x ⇒ x+4x=100 ⇒ x=20, y=40 (बिंदु: 20, 40)

P2: 2x-y=0 और 2x+y=200 ⇒ 4x=200 ⇒ x=50, y=100 (बिंदु: 50, 100)

P3: x+2y=100 और 2x+y=200 ⇒ y=200-2x ⇒ x+400-4x=100 ⇒ 3x=300 ⇒ x=100, y=0 (बिंदु: 100, 0)

सुसंगत क्षेत्र के कोनीय बिंदु: A(20,40), B(50,100), C(100,0)

Z = x + 2y का मान:

A(20, 40): Z = 20 + 80 = 100

B(50, 100): Z = 50 + 200 = 250

C(100, 0): Z = 100 + 0 = 100

उत्तर: न्यूनतम मान 100 है (बिंदुओं (20, 40) और (100, 0) पर) और अधिकतम मान 250 है (बिंदु (50, 100) पर)।

प्रश्न 9: निम्न अवरोधों के अंतर्गत Z = -x + 2y का अधिकतमीकरण कीजिए: x ≥ 3, x + y ≥ 5, x + 2y ≥ 6, y ≥ 0

हल: दिए गए अवरोध हैं:

x ≥ 3 ...(1)

x + y ≥ 5 ...(2)

x + 2y ≥ 6 ...(3)

y ≥ 0 ...(4)

सुसंगत क्षेत्र अपरिबद्ध है। कोनीय बिंदु:

P1: x=3 और x+y=5 ⇒ y=2 (बिंदु: 3, 2)

P2: x+y=5 और x+2y=6 ⇒ y=1, x=4 (बिंदु: 4, 1)

P3: x+2y=6 और y=0 ⇒ x=6 (बिंदु: 6, 0)

Z = -x + 2y का मान:

(3, 2): Z = -3 + 4 = 1

(4, 1): Z = -4 + 2 = -2

(6, 0): Z = -6 + 0 = -6

चूँकि सुसंगत क्षेत्र अपरिबद्ध है, हम असमिका Z > 1 ⇒ -x + 2y > 1 की जाँच करते हैं। यह अर्धतल सुसंगत क्षेत्र के साथ उभयनिष्ठ बिंदु रखता है (जैसे कि बिंदु x=3, y=10 के लिए Z=17 > 1)।

उत्तर: अतः Z का कोई अधिकतम मान नहीं है (Z अनंत तक जा सकता है)।

प्रश्न 10: निम्न अवरोधों के अंतर्गत Z = x + y का अधिकतमीकरण कीजिए: x - y ≤ -1, -x + y ≤ 0, x, y ≥ 0

हल: दिए गए अवरोध हैं:

x - y ≤ -1 ⇒ y ≥ x + 1 ...(1)

-x + y ≤ 0 ⇒ y ≤ x ...(2)

x, y ≥ 0 ...(3)

(1) और (2) से, हमें प्राप्त होता है: x + 1 ≤ y ≤ x

इसका अर्थ है कि x + 1 ≤ x, जो कि 1 ≤ 0 है, जो सत्य नहीं है।

उत्तर: अतः दिए गए अवरोधों के लिए कोई भी सुसंगत क्षेत्र नहीं है। इसलिए समस्या का कोई हल नहीं है।
