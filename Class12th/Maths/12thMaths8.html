प्रश्नावली 8.1

प्रश्न 1: दीर्घवृत्त x216 + y29 = 1 से घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: दिया गया दीर्घवृत्त है: x242 + y232 = 1

यहाँ अर्ध-दीर्घ अक्ष a = 4 और अर्ध-लघु अक्ष b = 3 है।

दीर्घवृत्त x-अक्ष और y-अक्ष दोनों के परितः सममित है। अतः इससे घिरे क्षेत्र का कुल क्षेत्रफल, प्रथम चतुर्थांश में घिरे क्षेत्र के क्षेत्रफल का 4 गुना होगा।

प्रथम चतुर्थांश में, y = 3√(1 - x2/16) = 34√(16 - x2)

क्षेत्रफल = 4 ∫04 y dx = 4 ∫04 34√(16 - x2) dx

= 3 ∫04 √(42 - x2) dx

सूत्र ∫ √(a2 - x2) dx = x2√(a2 - x2) + a22 sin-1(xa) का प्रयोग करने पर:

= 3 [x2√(16 - x2) + 162 sin-1(x4)]04

= 3 [(0 + 8 sin-1(1)) - (0 + 0)]

= 3 [8 × π2] = 12π

उत्तर: 12π वर्ग इकाई

प्रश्न 2: दीर्घवृत्त x24 + y29 = 1 से घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: दिया गया दीर्घवृत्त है: x222 + y232 = 1

यहाँ x-अक्ष के अनुदिश अर्ध-अक्ष a = 2 और y-अक्ष के अनुदिश b = 3 है।

दीर्घवृत्त से घिरे क्षेत्र का कुल क्षेत्रफल = πab

= π × 2 × 3 = 6π

उत्तर: 6π वर्ग इकाई

प्रश्न 3: प्रथम चतुर्थांश में वृत्त x2 + y2 = 4 एवं रेखाओं x = 0, x = 2 से घिरे क्षेत्र का क्षेत्रफल है:

(A) π    (B) π/2    (C) π/3    (D) π/4

हल: दिया गया वृत्त x2 + y2 = 4 है, जिसकी त्रिज्या r = 2 है।

प्रथम चतुर्थांश में, y = √(4 - x2)

क्षेत्रफल = ∫02 √(4 - x2) dx

= [x2√(4 - x2) + 42 sin-1(x2)]02

= (0 + 2 sin-1(1)) - (0 + 0) = 2 × π2 = π

(दूसरी विधि: प्रथम चतुर्थांश में वृत्त का क्षेत्रफल = 14 × πr2 = 14 × π(4) = π)

उत्तर: विकल्प (A) सही है।

प्रश्न 4: वक्र y2 = 4x, y-अक्ष एवं रेखा y = 3 से घिरे क्षेत्र का क्षेत्रफल है:

(A) 2    (B) 9/4    (C) 9/3    (D) 9/2

हल: दिया गया वक्र y2 = 4x ⇒ x = y24 है।

y-अक्ष और रेखा y = 3 के बीच घिरा क्षेत्र y = 0 से y = 3 तक होगा।

क्षेत्रफल = ∫03 x dy = ∫03 y24 dy

= [y312]03 = 2712 = 94

उत्तर: विकल्प (B) सही है।

विविध प्रश्नावली (Miscellaneous Exercise)

प्रश्न 1: वक्र y2 = x, रेखाओं x = 1, x = 4 तथा x-अक्ष से घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: दिया गया वक्र y2 = x ⇒ y = √x है। (चूँकि प्रथम चतुर्थांश में y धनात्मक है)

x-अक्ष और रेखाओं x = 1, x = 4 के बीच घिरा क्षेत्र:

क्षेत्रफल = ∫14 y dx = ∫14 x1/2 dx

= [x3/23/2]14 = 23 [x3/2]14

= 23 (43/2 - 13/2) = 23 (8 - 1) = 143

उत्तर: 143 वर्ग इकाई

प्रश्न 2: वक्र y2 = 9x, x = 2, x = 4 तथा x-अक्ष से प्रथम चतुर्थांश में घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: दिया गया वक्र y2 = 9x ⇒ y = 3√x है। (प्रथम चतुर्थांश में)

क्षेत्रफल = ∫24 y dx = ∫24 3x1/2 dx

= 3 [x3/23/2]24 = 2 [x3/2]24

= 2 (43/2 - 23/2) = 2 (8 - 2√2) = 16 - 4√2

उत्तर: (16 - 4√2) वर्ग इकाई

प्रश्न 3: वक्र x2 = 4y, y = 2, y = 4 तथा y-अक्ष से प्रथम चतुर्थांश में घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: दिया गया वक्र x2 = 4y ⇒ x = 2√y है। (प्रथम चतुर्थांश में)

क्षेत्रफल = ∫24 x dy = ∫24 2y1/2 dy

= 2 [y3/23/2]24 = 43 [y3/2]24

= 43 (43/2 - 23/2) = 43 (8 - 2√2)

उत्तर: 43 (8 - 2√2) वर्ग इकाई

प्रश्न 4: दीर्घवृत्त x216 + y29 = 1 से घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: यह प्रश्न प्रश्नावली 8.1 के प्रश्न 1 के समान है।

दीर्घवृत्त का समीकरण: x242 + y232 = 1

यहाँ a = 4 और b = 3 है।

कुल क्षेत्रफल = πab

= π × 4 × 3 = 12π

उत्तर: 12π वर्ग इकाई

प्रश्न 5: रेखाओं 2x + y = 4, 3x - 2y = 6 एवं x - 3y + 5 = 0 से घिरे क्षेत्र का क्षेत्रफल ज्ञात कीजिए।

हल: दी गई रेखाओं के प्रतिच्छेदन बिंदु ज्ञात करते हैं:

(1) L1 और L2 का प्रतिच्छेदन: 2x + y = 4 और 3x - 2y = 6

y = 4 - 2x को दूसरे में रखने पर: 3x - 2(4 - 2x) = 6 ⇒ 7x = 14 ⇒ x = 2, y = 0. बिंदु: A(2, 0)

(2) L2 और L3 का प्रतिच्छेदन: 3x - 2y = 6 और x - 3y = -5

x = 3y - 5 रखने पर: 3(3y - 5) - 2y = 6 ⇒ 7y = 21 ⇒ y = 3, x = 4. बिंदु: B(4, 3)

(3) L3 और L1 का प्रतिच्छेदन: x - 3y = -5 और 2x + y = 4

x = 3y - 5 रखने पर: 2(3y - 5) + y = 4 ⇒ 7y = 14 ⇒ y = 2, x = 1. बिंदु: C(1, 2)

अतः तीनों रेखाएँ एक त्रिभुज बनाती हैं जिसके शीर्ष A(2, 0), B(4, 3), C(1, 2) हैं।

त्रिभुज का क्षेत्रफल = 12 |x1(y2 - y3) + x2(y3 - y1) + x3(y1 - y2)|

= 12 |2(3 - 2) + 4(2 - 0) + 1(0 - 3)|

= 12 |2(1) + 4(2) + 1(-3)| = 12 |2 + 8 - 3| = 72

उत्तर: 72 वर्ग इकाई
