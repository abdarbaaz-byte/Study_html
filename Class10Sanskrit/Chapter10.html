दशमः पाठः

अन्योक्तयः

प्रश्नः 1. एकपदेन उत्तरं लिखत–

(क) कस्य शोभा एकेन राजहंसेन भवति?
उत्तरम्- सरसः।

(ख) सरसः तीरे के वसन्ति?
उत्तरम्- बकाः।

(ग) कः पिपासितः भवति?
उत्तरम्- चातकः।

(घ) के रसालमुकुलानि समाश्रयन्ते?
उत्तरम्- भूङ्गाः।

(ङ) अम्भोदाः कुत्र सन्ति?
उत्तरम्- गगने।

प्रश्नः 2. अधोलिखितानां प्रश्नानाम् उत्तराणि संस्कृतभाषया लिखत–

(क) सरसः शोभा केन भवति?
उत्तरम्- एकेन राजहंसेन सरसः शोभा भवति।

(ख) चातकः किमर्थं मानी कथ्यते?
उत्तरम्- चातकः एक एव खगः मानी वने वसति, पिपासितः अपि इन्द्रं याचते, अतः मानी कथ्यते।

(ग) मीनः कदा दीनां गतिं प्राप्नोति?
उत्तरम्- सरसि सङ्कोचम् अञ्चति सति मीनः दीनां गतिं प्राप्नोति।

(घ) कानन पूरयित्वा जलदः रिक्तः भवति?
उत्तरम्- नानानदीनदशतानि पूरयित्वा जलदः रिक्तः भवति।

(ङ) वृष्टिभिः वसुधां के आर्द्रयन्ति?
उत्तरम्- केचित् अम्भोदाः वृष्टिभिः वसुधां आर्द्रयन्ति।

प्रश्नः 3. अधोलिखितवाक्येषु रेखाङ्कितपदानि आधृत्य प्रश्ननिर्माणं कुरुत–

(क) मालाकारः तोयैः तरोः पुष्टिं करोति।
उत्तरम्- कः तोयैः तरोः पुष्टिं करोति?

(ख) भूङ्गाः रसालमुकुलानि समाश्रयन्ते।
उत्तरम्- के रसालमुकुलानि समाश्रयन्ते?

(ग) पतङ्गाः अम्बरपथम् आपेदिरे।
उत्तरम्- के अम्बरपथम् आपेदिरे?

(घ) जलदः नानानदीनदशतानि पूरयित्वा रिक्तोऽस्ति।
उत्तरम्- कः नानानदीनदशतानि पूरयित्वा रिक्तोऽस्ति?

(ङ) चातकः वने वसति।
उत्तरम्- कः वने वसति?

प्रश्नः 4. अधोलिखितयोः श्लोकयोः भावार्थं स्वीकृतभाषया लिखत–

(अ) तोयैरल्पैरपि करुणया भीमभानौ निदाघे, मालाकार! व्यरचि भवता या तरोरस्य पुष्टिः। सा किं शक्या जनयितुमिह प्रावृषेण्येन वारां, धारासारानपि विकिरता विश्वतो वारिदेन॥
उत्तरम्- हे मालाकार! भीमभानौ निदाघे अल्पैः तोयैः अपि भवता करुणया अस्य तरोः या पुष्टिः व्यरचि। विश्वतः वारां धारासारान् अपि विकिरता प्रावृषेण्येन वारिदेन इह जनयितुम् सा पुष्टिः किं शक्या?

(आ) रे रे चातक! सावधानमनसा मित्र! क्षणं श्रूयताम्। अम्भोदा बहवो भवन्ति गगने सर्वेऽपि नैतादृशाः। केचिद् वृष्टिभिरार्द्रयन्ति वसुधां गर्जन्ति केचिद् वृथा, यं यं पश्यसि तस्य तस्य पुरतो मा ब्रूहि दीनं वचः॥
उत्तरम्- हे मित्र चातक! सावधानमनसा क्षणं श्रूयताम्। गगने हि बहवः अम्भोदाः सन्ति, सर्वे अपि एतादृशाः न सन्ति। केचित् वसुधां वृष्टिभिः आर्द्रयन्ति, केचित् वृथा गर्जन्ति। त्वं यं यं पश्यसि तस्य तस्य पुरतः दीनं वचः मा ब्रूहि।

प्रश्नः 5. अधोलिखितयोः श्लोकयोः अन्वयं लिखत–

(अ) आपेदिरे ....................... कतमां गतिमभ्युपैति।
उत्तरम्- पतङ्गाः परितः अम्बरपथम् आपेदिरे, भूङ्गाः रसालमुकुलानि समाश्रयन्ते, सरः त्वयि सङ्कोचम् अञ्चति, हन्त दीनदीनः मीनः नु कतमां गतिम् अभ्युपैतु।

(आ) आश्वास्य ....................... सैव तवोत्तमा श्रीः।
उत्तरम्- हे जलद! तपनोष्णतप्तं पर्वतकुलम् आश्वास्य, उद्दामदावविधुराणि काननानि च आश्वास्य, नानानदीनदशतानि पूरयित्वा च यत् रिक्तोऽसि, सा एव तव उत्तमा श्रीः।

प्रश्नः 6. उदाहरणमनुसृत्य सन्धिं/सन्धिविच्छेदं वा कुरुत–

(i) यथा- अन्य + उक्तयः = अन्योक्तयः

(क) निपीतानि + अम्बूनि = निपीतान्यम्बूनि

(ख) कृतः + उपकारः = कृतोपकारः

(ग) तपन + उष्णतप्तम् = तपनोष्णतप्तम्

(घ) तव + उत्तमा = तवोत्तमा

(ङ) न + एतादृशाः = नैतादृशाः

(ii) यथा- पिपासितः + अपि = पिपासितोऽपि

(क) कः + अपि = कोऽपि

(ख) रिक्तः + असि = रिक्तोऽसि

(ग) मीनः + अयम् = मीनोऽयम्

(घ) सर्वे + अपि = सर्वेऽपि

(iii) यथा- सरसः + भवेत् = सरसो भवेत्

(क) खगः + मानी = खगो मानी

(ख) मीनः + तु = मीनो तु

(ग) पिपासितः + वा = पिपासितो वा

(घ) पुरतः + मा = पुरतो मा

(iv) यथा- मीनः + अपि = मीनोऽपि

(क) तोयैः + अल्पैः = तोयैरल्पैः

(ख) अल्पैः + अपि = अल्पैरपि

(ग) तरोः + अपि = तरोरपि

(घ) वृष्टिभिः + आर्द्रयन्ति = वृष्टिभिरार्द्रयन्ति
