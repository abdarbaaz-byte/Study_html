प्रश्नावली 6.1

प्रश्न 1: आकृति 6.13 में, रेखाएँ AB और CD बिंदु O पर प्रतिच्छेद करती हैं। यदि ∠AOC + ∠BOE = 70° और ∠BOD = 40° है, तो ∠BOE और प्रतिवर्ती ∠COE ज्ञात कीजिए।

हल:

दिया है: ∠AOC + ∠BOE = 70° और ∠BOD = 40°

आकृति से, ∠AOC = ∠BOD (शीर्षाभिमुख कोण)

अतः, ∠AOC = 40°

अब, ∠AOC + ∠BOE = 70°

40° + ∠BOE = 70°

∠BOE = 70° − 40° = 30°

अब, ∠AOC + ∠COE + ∠BOE = 180° (एक सरल रेखा पर कोण)

40° + ∠COE + 30° = 180°

∠COE = 180° − 70° = 110°

प्रतिवर्ती ∠COE = 360° − 110° = 250°

उत्तर: ∠BOE = 30°, प्रतिवर्ती ∠COE = 250°

हिंदी स्पष्टीकरण: दिया गया है ∠AOC + ∠BOE = 70° और ∠BOD = 40°। शीर्षाभिमुख कोणों के कारण ∠AOC = ∠BOD = 40°। इससे ∠BOE = 30° मिलता है। सरल रेखा पर कोणों का योग 180° होता है, इसलिए ∠COE = 110° और प्रतिवर्ती कोण 360° − 110° = 250° होगा।

प्रश्न 2: आकृति 6.14 में, रेखाएँ XY और MN बिंदु O पर प्रतिच्छेद करती हैं। यदि ∠POY = 90° और a : b = 2 : 3 है, तो c ज्ञात कीजिए।

हल:

दिया है: ∠POY = 90° और a : b = 2 : 3

मान लीजिए a = 2x और b = 3x

आकृति से, ∠POY + ∠POX = 180° (रैखिक युग्म)

90° + a + b = 180°

90° + 2x + 3x = 180°

5x = 90°

x = 18°

अतः, a = 2 × 18° = 36°, b = 3 × 18° = 54°

अब, ∠XON = ∠YOM = c (शीर्षाभिमुख कोण)

साथ ही, ∠XON + ∠NOM = 180° (रैखिक युग्म)

c + b = 180°

c + 54° = 180°

c = 180° − 54° = 126°

उत्तर: c = 126°

हिंदी स्पष्टीकरण: दिया गया है ∠POY = 90° और a : b = 2 : 3। रैखिक युग्म के कारण 90° + a + b = 180°। a = 2x, b = 3x रखने पर x = 18° मिलता है। शीर्षाभिमुख कोणों और रैखिक युग्म के कारण c + b = 180°, इसलिए c = 126°।

प्रश्न 3: आकृति 6.15 में, ∠PQR = ∠PRQ है, तो सिद्ध कीजिए कि ∠PQS = ∠PRT है।

हल:

दिया है: ∠PQR = ∠PRQ

सिद्ध करना है: ∠PQS = ∠PRT

∠PQS + ∠PQR = 180° (रैखिक युग्म) ...(1)

∠PRT + ∠PRQ = 180° (रैखिक युग्म) ...(2)

(1) और (2) से:

∠PQS + ∠PQR = ∠PRT + ∠PRQ

परन्तु ∠PQR = ∠PRQ (दिया है)

अतः, ∠PQS = ∠PRT

अतः सिद्ध हुआ।

हिंदी स्पष्टीकरण: दिया गया है ∠PQR = ∠PRQ। रैखिक युग्म के कारण ∠PQS + ∠PQR = 180° और ∠PRT + ∠PRQ = 180°। दोनों समीकरणों को बराबर रखने पर, और ∠PQR = ∠PRQ प्रतिस्थापित करने पर, ∠PQS = ∠PRT मिलता है।

प्रश्न 4: आकृति 6.16 में, यदि x + y = w + z है, तो सिद्ध कीजिए कि AOB एक सरल रेखा है।

हल:

दिया है: x + y = w + z

सिद्ध करना है: AOB एक सरल रेखा है

हम जानते हैं कि एक बिंदु के चारों ओर सभी कोणों का योग 360° होता है।

अतः, x + y + w + z = 360°

परन्तु x + y = w + z (दिया है)

अतः, x + y + x + y = 360°

2(x + y) = 360°

x + y = 180°

इसका अर्थ है कि ∠AOC और ∠BOC एक रैखिक युग्म बनाते हैं।

इसलिए, AOB एक सरल रेखा है।

अतः सिद्ध हुआ।

हिंदी स्पष्टीकरण: दिया गया है x + y = w + z। बिंदु O पर सभी कोणों का योग 360° होता है, इसलिए x + y + w + z = 360°। x + y = w + z प्रतिस्थापित करने पर 2(x + y) = 360°, यानी x + y = 180°। इसका मतलब ∠AOC और ∠BOC रैखिक युग्म बनाते हैं, इसलिए AOB एक सरल रेखा है।

प्रश्न 5: आकृति 6.17 में, POQ एक रेखा है। किरण OR रेखा PQ पर लंब है। OS किरण OP और OR के बीच में स्थित एक अन्य किरण है। सिद्ध कीजिए कि ∠ROS =
12
(∠QOS − ∠POS) है।

हल:

दिया है: POQ एक सरल रेखा है, OR ⊥ PQ

सिद्ध करना है: ∠ROS =

12
(∠QOS − ∠POS)

चूँकि OR ⊥ PQ, इसलिए ∠POR = 90° और ∠ROQ = 90°

∠QOS = ∠QOR + ∠ROS ...(1)

∠POS = ∠POR − ∠ROS ...(2)

(1) में से (2) घटाने पर:

∠QOS − ∠POS = (∠QOR + ∠ROS) − (∠POR − ∠ROS)

= ∠QOR + ∠ROS − ∠POR + ∠ROS

= 90° + ∠ROS − 90° + ∠ROS

= 2∠ROS

अतः, ∠ROS =

12
(∠QOS − ∠POS)

अतः सिद्ध हुआ।

हिंदी स्पष्टीकरण: दिया गया है POQ एक सरल रेखा है और OR ⊥ PQ। इसका मतलब ∠POR = 90° और ∠ROQ = 90°। ∠QOS = ∠QOR + ∠ROS और ∠POS = ∠POR − ∠ROS। दोनों समीकरणों को घटाने पर ∠QOS − ∠POS = 2∠ROS मिलता है, इसलिए ∠ROS = 1/2 (∠QOS − ∠POS)।

प्रश्न 6: दिया गया है ∠XYZ = 64° है और XY को बिंदु P तक बढ़ाया गया है। दी हुई सूचना से एक आकृति खींचिए। यदि किरण YQ, ∠ZYP को समद्विभाजित करती है, तो ∠XYQ और प्रतिवर्ती ∠QYP ज्ञात कीजिए।

हल:

दिया है: ∠XYZ = 64°, XY को P तक बढ़ाया गया, YQ, ∠ZYP को समद्विभाजित करता है

∠XYZ + ∠ZYP = 180° (रैखिक युग्म)

64° + ∠ZYP = 180°

∠ZYP = 180° − 64° = 116°

चूँकि YQ, ∠ZYP को समद्विभाजित करता है, इसलिए ∠ZYQ = ∠QYP =

12
× 116° = 58°

अब, ∠XYQ = ∠XYZ + ∠ZYQ = 64° + 58° = 122°

प्रतिवर्ती ∠QYP = 360° − ∠QYP = 360° − 58° = 302°

उत्तर: ∠XYQ = 122°, प्रतिवर्ती ∠QYP = 302°

हिंदी स्पष्टीकरण: दिया गया है ∠XYZ = 64° और XY को P तक बढ़ाया गया है। रैखिक युग्म के कारण ∠XYZ + ∠ZYP = 180°, इसलिए ∠ZYP = 116°। YQ, ∠ZYP को समद्विभाजित करता है, इसलिए ∠ZYQ = ∠QYP = 58°। ∠XYQ = ∠XYZ + ∠ZYQ = 122°। प्रतिवर्ती ∠QYP = 360° − 58° = 302°।

प्रश्नावली 6.2

प्रश्न 1: आकृति 6.23 में, यदि AB ∥ CD, CD ∥ EF और y : z = 3 : 7 है, तो x ज्ञात कीजिए।

हल:

दिया है: AB ∥ CD, CD ∥ EF, y : z = 3 : 7

चूँकि CD ∥ EF, इसलिए x + y = 180° (तिर्यक रेखा के एक ही ओर के अंतः कोण)

चूँकि AB ∥ CD, इसलिए x = z (संगत कोण)

मान लीजिए y = 3k और z = 7k

तब x = z = 7k

अब, x + y = 180°

7k + 3k = 180°

10k = 180°

k = 18°

अतः, x = 7k = 7 × 18° = 126°

उत्तर: x = 126°

हिंदी स्पष्टीकरण: दिया गया है AB ∥ CD, CD ∥ EF और y : z = 3 : 7। CD ∥ EF होने के कारण x + y = 180° (तिर्यक रेखा के एक ही ओर के अंतः कोण)। AB ∥ CD होने के कारण x = z (संगत कोण)। y = 3k, z = 7k मानकर x = 7k मिलता है। समीकरण 7k + 3k = 180° हल करने पर k = 18°, इसलिए x = 126°।

प्रश्न 2: आकृति 6.24 में, यदि AB ∥ CD, EF ⊥ CD और ∠GED = 126° है, तो ∠AGE, ∠GEF और ∠FGE ज्ञात कीजिए।

हल:

दिया है: AB ∥ CD, EF ⊥ CD, ∠GED = 126°

चूँकि AB ∥ CD, इसलिए ∠AGE = ∠GED = 126° (एकांतर अंतः कोण)

EF ⊥ CD, इसलिए ∠FED = 90°

∠GED = ∠GEF + ∠FED

126° = ∠GEF + 90°

∠GEF = 126° − 90° = 36°

त्रिभुज GEF में, ∠GEF + ∠EGF + ∠FGE = 180°

परन्तु ∠EGF = 90° (चूँकि EF ⊥ CD और AB ∥ CD, इसलिए EF ⊥ AB)

36° + 90° + ∠FGE = 180°

∠FGE = 180° − 126° = 54°

उत्तर: ∠AGE = 126°, ∠GEF = 36°, ∠FGE = 54°

हिंदी स्पष्टीकरण: दिया गया है AB ∥ CD, EF ⊥ CD और ∠GED = 126°। एकांतर अंतः कोणों के कारण ∠AGE = ∠GED = 126°। EF ⊥ CD होने के कारण ∠FED = 90°, इसलिए ∠GEF = 126° − 90° = 36°। त्रिभुज GEF में कोण योग गुण का उपयोग करने पर ∠FGE = 54° मिलता है।

प्रश्न 3: आकृति 6.25 में, यदि PQ ∥ ST, ∠PQR = 110° और ∠RST = 130° है, तो ∠QRS ज्ञात कीजिए।

हल:

दिया है: PQ ∥ ST, ∠PQR = 110°, ∠RST = 130°

बिंदु R से होकर ST के समांतर एक रेखा RU खींचिए।

चूँकि RU ∥ ST और PQ ∥ ST, इसलिए RU ∥ PQ

∠PQR + ∠QRU = 180° (तिर्यक रेखा के एक ही ओर के अंतः कोण)

110° + ∠QRU = 180°

∠QRU = 70°

∠RST + ∠SRU = 180° (तिर्यक रेखा के एक ही ओर के अंतः कोण)

130° + ∠SRU = 180°

∠SRU = 50°

∠QRS = ∠QRU + ∠SRU = 70° + 50° = 120°

उत्तर: ∠QRS = 120°

हिंदी स्पष्टीकरण: दिया गया है PQ ∥ ST, ∠PQR = 110° और ∠RST = 130°। बिंदु R से ST के समांतर एक रेखा RU खींचते हैं। RU ∥ ST और PQ ∥ ST होने के कारण RU ∥ PQ। तिर्यक रेखा के एक ही ओर के अंतः कोणों के कारण ∠QRU = 70° और ∠SRU = 50°। इसलिए ∠QRS = 70° + 50° = 120°।

प्रश्न 4: आकृति 6.26 में, यदि AB ∥ CD, ∠APQ = 50° और ∠PRD = 127° है, तो x और y ज्ञात कीजिए।

हल:

दिया है: AB ∥ CD, ∠APQ = 50°, ∠PRD = 127°

चूँकि AB ∥ CD, इसलिए ∠APQ = ∠PQR = 50° (एकांतर अंतः कोण)

अतः, x = 50°

साथ ही, ∠PRD = ∠APR = 127° (एकांतर अंतः कोण)

अब, ∠APR = ∠APQ + ∠QPR

127° = 50° + y

y = 127° − 50° = 77°

उत्तर: x = 50°, y = 77°

हिंदी स्पष्टीकरण: दिया गया है AB ∥ CD, ∠APQ = 50° और ∠PRD = 127°। एकांतर अंतः कोणों के कारण ∠APQ = ∠PQR = 50°, इसलिए x = 50°। एकांतर अंतः कोणों के कारण ∠PRD = ∠APR = 127°। ∠APR = ∠APQ + ∠QPR, इसलिए 127° = 50° + y, y = 77°।

प्रश्न 5: आकृति 6.27 में, PQ और RS दो दर्पण हैं जो एक-दूसरे के समांतर रखे गए हैं। एक आपतित किरण AB, दर्पण PQ को बिंदु B पर टकराती है, परावर्तित किरण BC के पथ पर चलती है और दर्पण RS को बिंदु C पर टकराती है तथा पुनः CD के पथ पर परावर्तित हो जाती है। सिद्ध कीजिए कि AB ∥ CD है।

हल:

सिद्ध करना है: AB ∥ CD

बिंदुओं B और C पर अभिलंब खींचिए।

परावर्तन के नियमों के अनुसार:

आपतन कोण = परावर्तन कोण

अतः, बिंदु B पर: ∠ABN = ∠NBC

बिंदु C पर: ∠BCM = ∠MCD

चूँकि PQ ∥ RS, इसलिए अभिलंब BN और CM समांतर हैं।

अतः, ∠NBC = ∠BCM (एकांतर अंतः कोण)

इसलिए, ∠ABN = ∠MCD

परन्तु ये रेखाओं AB और CD के लिए तिर्यक रेखा BC के साथ एकांतर अंतः कोण हैं।

अतः, AB ∥ CD

अतः सिद्ध हुआ।

हिंदी स्पष्टीकरण: PQ और RS दो समांतर दर्पण हैं। परावर्तन के नियमों के अनुसार आपतन कोण = परावर्तन कोण। बिंदु B पर ∠ABN = ∠NBC और बिंदु C पर ∠BCM = ∠MCD। PQ ∥ RS होने के कारण अभिलंब BN और CM समांतर हैं, इसलिए ∠NBC = ∠BCM (एकांतर अंतः कोण)। इससे ∠ABN = ∠MCD मिलता है, जो AB और CD के लिए एकांतर अंतः कोण हैं, इसलिए AB ∥ CD।

📌 अध्याय 6 का सारांश

1. यदि दो रेखाएँ एक-दूसरे को काटती हैं, तो शीर्षाभिमुख कोण बराबर होते हैं।

2. यदि एक किरण एक रेखा पर खड़ी हो, तो बने दो आसन्न कोणों का योग 180° होता है, जिन्हें रैखिक युग्म कहते हैं।

3. यदि दो समांतर रेखाओं को एक तिर्यक रेखा काटती है, तो:

  • संगत कोणों का प्रत्येक युग्म बराबर होता है।
  • एकांतर अंतः कोणों का प्रत्येक युग्म बराबर होता है।
  • तिर्यक रेखा के एक ही ओर के अंतः कोणों का प्रत्येक युग्म संपूरक होता है।

4. वे रेखाएँ जो एक ही रेखा के समांतर हों, परस्पर समांतर होती हैं।

5. त्रिभुज के तीनों कोणों का योग 180° होता है (कोण योग गुण)।

6. यदि एक तिर्यक रेखा दो रेखाओं को इस प्रकार काटती है कि संगत कोण बराबर हों, तो रेखाएँ समांतर होती हैं।
